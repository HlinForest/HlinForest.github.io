AI Infra 前置基础术语表

统一课程中的语言、数学、模型、框架、硬件和通信术语。

语言与系统

IdentityPython 对象身份；is 比较身份而非值。
Mutability对象的值能否原地改变。
RAII资源获取即初始化；资源生命周期绑定对象生命周期。
Ownership谁负责保持资源存活并最终释放。
ABI二进制调用约定、符号、对象布局和运行库接口。
Shared library运行时装载和解析的动态库，如 Linux .so。
Signal内核或进程发送给进程的异步通知，如 SIGTERM。
Process拥有独立地址空间和系统资源的执行实例。

Tensor 与数学

ShapeTensor 各逻辑维度的长度。
Stride某维索引增加 1 时底层地址跨过的元素数。
Layout逻辑索引到物理存储的组织方式。
Broadcast按兼容维度逻辑扩展 Tensor 的规则。
Reduction沿某些维度聚合，如 sum、max、mean。
GEMM通用矩阵乘：C=αAB+βC。
Tiling把计算分块，使数据在快存储中复用。
FLOPs浮点操作数量；常把乘和加各计一次。
Arithmetic intensity每搬运一个字节完成的 FLOPs。
Rank矩阵独立方向数量；注意与分布式 rank 同名不同义。
SVD奇异值分解，用排序方向解释低秩近似。
LogitsSoftmax 前的任意实数分数。
Cross entropy目标分布对模型分布的负对数评分。
Autodiff沿计算图自动应用链式法则。

Transformer 与推理

TokenTokenizer 产生的离散文本单元。
Embedding把 token ID 映射为连续向量。
Q/K/VAttention 的查询、键和值投影。
Causal mask阻止位置看到未来 token 的上三角屏蔽。
MHA/MQA/GQA多头、单 KV 头、分组 KV 头 Attention。
RoPE通过旋转 Q/K 编码位置关系。
RMSNorm按均方根缩放、不减均值的归一化。
SwiGLUSiLU 门控的 FFN 结构。
Prefill并行处理整个 prompt 并建立 KV Cache。
Decode每步生成一个新 token 的自回归阶段。
KV Cache保存历史 token 在每层的 K/V，避免重复计算。
TTFT/TPOT首 token 时间 / 每输出 token 时间。

GPU 与通信

SMGPU 上调度 Warp、执行指令并拥有片上资源的处理单元。
WarpNVIDIA GPU 上 32 个线程的调度组。
SIMT单指令、多线程的执行模型。
Tensor Core高吞吐矩阵乘累加单元。
Coalescing把相邻线程的内存访问合并成较少事务。
OccupancySM 活跃 Warp 相对硬件上限的比例。
Roofline用峰值算力和带宽×算术强度描述性能上限。
Distributed rank进程在通信组中的编号。
Collective通信组中所有 rank 共同参与的数据操作。
AllReduce归约所有输入，并把结果给所有 rank。
ReduceScatter归约后把结果分片给各 rank。
NCCLNVIDIA GPU 集合通信库。
RDMA网卡直接访问注册内存，减少 CPU 与复制参与。
Overlap让通信与独立计算在时间上重叠。
