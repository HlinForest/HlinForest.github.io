概率、反向传播与数值稳定

目标：理解 logits 如何变成分布、梯度如何沿图传播，以及有限精度为何让数学等式在硬件上失效。

过关标准

  • 能实现稳定 Softmax、LogSumExp 和交叉熵。
  • 能解释温度、熵与 KL 散度的含义。
  • 能手推线性层与 Softmax 交叉熵梯度。
  • 能解释梯度累积、消失、爆炸、裁剪、残差和归一化。
  • 能比较 FP32、TF32、FP16、BF16、FP8 的范围与精度。

1. 从 logits 到概率

pᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)

logits 是任意实数，不是概率。Softmax 输出为正且和为 1。它对统一平移不敏感，因此稳定实现先减最大值：

def stable_softmax(z):
    m = max(z)
    exps = [math.exp(v - m) for v in z]
    total = sum(exps)
    return [v / total for v in exps]

若直接对很大的 logits 求指数，会 overflow；先减最大值把最大指数固定为 1。

2. 交叉熵、熵和 KL

交叉熵 H(q,p) = -Σ qᵢ log pᵢ
熵 H(q) = -Σ qᵢ log qᵢ
KL(q||p) = Σ qᵢ log(qᵢ/pᵢ)
H(q,p) = H(q) + KL(q||p)

one-hot 标签下，交叉熵就是正确类别负对数概率。温度 T 通过 softmax(z/T) 调节分布：T 小更尖锐，T 大更平坦。

3. 链式法则与计算图

若 a=xy、b=a+x、L=b²，则 x 有两条路径影响 L，梯度必须相加：

∂L/∂x = 2b + 2by
∂L/∂y = 2bx

反向模式自动微分不显式构造巨大 Jacobian，而是计算 vector-Jacobian product。一个 Tensor 被多条路径使用时，梯度累积是数学要求。

4. 线性层反向仍是 GEMM

Y = XW + b
G = ∂L/∂Y
∂L/∂X = GWᵀ
∂L/∂W = XᵀG
∂L/∂b = reduce_sum(G, batch)

因此训练的反向传播并不是神秘黑盒：大量成本仍落在矩阵乘与归约上，只是 shape 和转置位置发生变化。

5. 梯度稳定性

  • 消失/爆炸：多层 Jacobian 连乘，奇异值长期小于或大于 1。
  • 残差连接：提供接近恒等映射的梯度路径。
  • 归一化：控制激活尺度，改善优化条件。
  • 梯度裁剪：限制范数，避免单次更新过大。
  • 初始化：让前向与反向的方差在深度上保持可控。

6. 精度与动态范围不是一件事

格式指数位尾数字段工程直觉
FP32823范围和精度较均衡
TF32810保留 FP32 范围，用于 Tensor Core 乘法语义
FP16510精度较细但范围较窄，常需 loss scaling
BF1687范围接近 FP32，但舍入更粗
FP84/53/2需缩放、校准和高精度累加

7. 五类数值风险

  1. overflow：绝对值超过最大有限值，变成 inf。
  2. underflow：太接近 0，进入 subnormal 或变成 0。
  3. 灾难性消减：两个接近的大数相减，剩余有效位很少。
  4. 非结合性：(a+b)+c 与 a+(b+c) 因舍入不同。
  5. 错误容差：只看相对误差会在参考值接近 0 时失真。
|x̂ - x| ≤ atol + rtol × |x|

并行归约顺序变化可能产生小数值差异。非逐位一致不必然是 Bug，但必须落在任务允许的容差内。

8. 混合精度的结构

常见做法是低精度保存或执行大部分矩阵计算，高精度累加敏感归约与参数更新。FP16 训练常用 loss scaling 把小梯度移入可表示范围；BF16 因指数范围较大，通常更少需要 scaling，但仍有舍入误差。
