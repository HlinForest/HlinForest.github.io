Decoder Block 完整数据流

目标：把 RMSNorm、RoPE、Attention、SwiGLU 与残差连接拼成一个完整可计算、可切分、可估算的 Block。

过关标准

  • 能从输入 hidden state 画出 Pre-Norm Decoder Block。
  • 能解释 RMSNorm、残差和 RoPE 的作用与 shape。
  • 能实现 SwiGLU FFN。
  • 能估算单个 Block 参数量和主要 FLOPs。
  • 能指出算子融合、张量并行和流水线并行的切入点。

1. Pre-Norm 数据流

h1 = x + Attention(RMSNorm(x))
out = h1 + FFN(RMSNorm(h1))

残差路径保持 shape (B,S,H) 不变。Pre-Norm 把归一化放在子层前，使深层网络梯度路径更稳定；残差提供接近恒等映射的直通路径。

2. RMSNorm

rms(x) = sqrt(mean(x²) + ε)
RMSNorm(x) = g ⊙ x / rms(x)

RMSNorm 沿隐藏维 H 做归约，不减均值。输入输出 shape 不变。工程实现需要平方、归约、rsqrt、缩放；常与 residual add 或邻接操作融合，减少 HBM 往返。

3. RoPE 把相对位置写入 Q/K

RoPE 把相邻维度视为二维坐标，根据位置旋转 Q 和 K。旋转保持 shape 和向量范数，但让 Q 与 K 的点积包含相对位置信息。

[x'₂ᵢ] [ cosθ -sinθ ][x₂ᵢ]
[x'₂ᵢ₊₁]=[ sinθ cosθ ][x₂ᵢ₊₁]

RoPE 计算量相对小但调用频繁，常融合进 Q/K 准备或 Attention Kernel。长上下文扩展涉及频率缩放和外推质量，不只是把位置上限改大。

4. SwiGLU FFN

FFN(x) = (SiLU(xW_gate) ⊙ xW_up) W_down

与两层标准 FFN 相比，SwiGLU 有 gate 与 up 两条投影，再逐元素相乘并降维。若中间维为 I：

  • W_gate: H×I
  • W_up: H×I
  • W_down: I×H

FFN 参数约 3HI，通常是 Block 参数与计算的大头之一，也是张量并行的主要切分对象。

5. 单 Block 参数账本

忽略 bias，以 MHA 为例：

组件参数量
Q/K/V 投影3H²
Attention 输出投影H²
SwiGLU FFN3HI
两个 RMSNorm2H
合计约 4H² + 3HI

若 I≈8H/3，FFN 约 8H²，整个 Block 约 12H²。实际模型的 GQA 会减小 K/V 投影参数。

7. 完整伪代码

def decoder_block(x, cache=None):
    n1 = rms_norm(x)
    q, k, v = qkv_projection(n1)
    q, k = apply_rope(q, k)
    a = causal_attention(q, k, v, cache)
    h = x + output_projection(a)
    n2 = rms_norm(h)
    f = silu(n2 @ W_gate) * (n2 @ W_up)
    return h + f @ W_down

阅读任何优化代码时，先把它放回这张数据流图：输入是什么、输出是什么、替换了哪一段、保持哪些语义不变。
