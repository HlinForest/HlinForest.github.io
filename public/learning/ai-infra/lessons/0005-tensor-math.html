张量、GEMM 与性能账本

目标：看到公式时立即回答 shape 是否正确、计算和存储代价多大、内存布局是否友好。

过关标准

  • 能推导广播、矩阵乘与 batched matmul 的输出 shape。
  • 能从 shape 和 stride 判断连续性与线性偏移。
  • 能解释 GEMM tiling 为什么数学等价、工程上为何更快。
  • 能估算参数量、激活量、FLOPs、最小访存量和算术强度。
  • 能解释秩、SVD 与 LoRA 的压缩直觉。

1. Tensor 不只是多维数组

Tensor = data pointer + shape + stride + dtype + device + layout

shape 描述逻辑索引空间；stride 描述每个维度前进 1 步时，底层地址跨过多少元素。两者相同的 Tensor 可能拥有不同布局。

# shape = (2, 3), row-major stride = (3, 1)
offset(i, j) = i * 3 + j

# 转置视图 shape = (3, 2), stride = (1, 3)
# 通常不复制，但最后一维不再连续

view 要求现有布局能直接解释成新 shape；reshape 必要时可以复制；permute 通常只改元数据；contiguous 会物化连续副本。

2. 广播：从尾部维度对齐

从最后一维向前比较，每对维度必须相等、至少一个为 1，或某一方没有该维度。

(B, S, H) + (H,) → (B, S, H)
(B, 1, H) + (1, S, 1) → (B, S, H)

广播通常是逻辑扩展，不先复制完整数据；但错误 shape 也可能“恰好能广播”，产生不报错的语义 Bug。

3. 矩阵乘法：归约内维

A ∈ R^(M×K), B ∈ R^(K×N)
C = A @ B ∈ R^(M×N)
C[i,j] = Σₖ A[i,k]B[k,j]
FLOPs ≈ 2MKN

记法：中间的 K 被归约，外侧 M、N 保留。多头 Attention 中：

Q: (B, Nh, Sq, Dh)
Kᵀ: (B, Nh, Dh, Sk)
QKᵀ: (B, Nh, Sq, Sk)

前面的维度是批处理维，最后两维做矩阵乘。

4. Tiling：少搬数据，不少算结果

把 A、B 分成小块，输出块仍满足：

Cᵢⱼ = Σₖ Aᵢₖ Bₖⱼ

每次将 A 和 B 的 tile 搬到更快的局部存储，复用后再加载下一块。FLOPs 仍近似 2MKN，但对慢速 HBM 的访问可显著减少。Tiling 的本质是改变数据移动与复用，不改变数学。

  1. 选择输出 tile。
  2. 沿 K 维分段加载 A/B tile。
  3. 在寄存器或共享内存中反复使用。
  4. 累加局部结果并最终写回。

5. 性能账本

账本计算方法用途
参数量所有权重元素数之和模型存储与优化器状态
激活量保存的中间 Tensor 元素数训练峰值显存
FLOPs乘法和加法通常各计一次计算工作量
Bytes读取 + 写入元素 × dtype 字节数据移动下界
算术强度FLOPs / Bytes判断带宽或算力瓶颈

Roofline 上限可粗略写为：

可达性能 ≤ min(峰值算力, 算术强度 × 峰值带宽)

如果算术强度低，提高更多计算单元通常没用；应优先减少读写、增加复用或融合中间结果。

6. 一个 GEMM 算例

设 M=N=K=4096，BF16 输入和输出，按最理想情况各读取 A/B 一次、写 C 一次：

  • FLOPs ≈ 2 × 4096³ ≈ 137.4 GFLOPs。
  • 最低数据量 ≈ (A+B+C) × 2 bytes ≈ 96 MiB。
  • 理想算术强度约 1430 FLOPs/byte。

真实实现还会受 cache、tile、累加 dtype、读写 C、对齐和边界块影响。账本是下界与方向，不是对实际性能的保证。

7. 秩、SVD 与 LoRA

秩可以理解为独立方向的数量。若大矩阵可由低秩因子近似：

W ≈ U V, U∈R^(M×r), V∈R^(r×N), r≪min(M,N)
参数量：MN → r(M+N)

SVD 给出按奇异值排序的方向；LoRA 冻结原权重，只训练低秩更新 ΔW = (α/r)BA。工程问题仍然是 shape、参数量、额外 GEMM 与是否合并权重。

实验：Tensor 账本

  1. 运行 tensor_math_lab.py。
  2. 手算每个 shape、stride、FLOPs 和字节数，再与程序输出核对。
  3. 比较朴素矩阵乘与分块矩阵乘的结果。
  4. 对给定算子判断 compute-bound 或 memory-bound，并说明假设。
