毕业项目 · 8–12 小时

跨层诊断一个慢且不稳定的训练任务

你将面对一组故意混合了代码、数值、环境、GPU 与通信问题的证据。目标不是猜中答案，而是形成可复现、可证伪的诊断报告。

毕业标准

总分 100，达到 80 分且“正确性”不低于 20/25 才通过。报告必须区分事实、推断和待验证假设。

场景

团队把一个 12 层 Decoder-only 小模型从单卡迁移到 8 卡训练。出现以下症状：

  • 有时前 200 步 loss 正常，随后变成 NaN。
  • 8 卡吞吐只有单卡的 3.1 倍。
  • GPU 利用率呈锯齿，周期性跌到接近 0。
  • 显存比估算高约 25%。
  • 某台机器偶尔在 AllReduce 处 hang。
  • 同一 checkpoint 在另一环境导入自定义扩展失败。

证据包位于 labs/capstone_case，包括环境审计、模型配置、训练片段、profile 摘要、NCCL 日志片段和拓扑。

任务 1：建立问题树

先不要给修复。把症状分到以下分支，并为每个分支写“最便宜且区分度最高的下一证据”：

  1. 语义/shape/layout 错误
  2. 数值稳定性
  3. 环境/ABI/动态库
  4. CPU 与数据加载
  5. GPU Kernel/内存
  6. 集合通信/拓扑

任务 2：正确性与数值

  1. 检查 mask、loss、梯度清零与混合精度顺序。
  2. 定位第一个非有限 Tensor，而不是只观察最终 loss。
  3. 用 FP32 参考路径与组合 atol/rtol 做对比。
  4. 为边界 shape、非连续输入与极端 logits 设计测试。

任务 3：内存账本

根据模型配置估算：

  • 参数、梯度与 AdamW 状态。
  • 主要激活与 Attention 中间量。
  • 混合精度与 master weights。
  • 通信 bucket、临时 workspace 与 allocator 保留。

解释“估算值”和 nvidia-smi 进程显存为何不完全相同。

任务 4：性能账本与时间线

  1. 从 profiler 把 step 时间分成 DataLoader、H2D、forward、backward、optimizer、collectives。
  2. 识别至少一个隐式同步和一个高频小 Kernel 模式。
  3. 为两个主要算子估算算术强度并形成 Roofline 假设。
  4. 提出优化时写清目标指标、预期变化、正确性检查与回退条件。

任务 5：通信

  1. 根据拓扑判断跨 NUMA、跨 PCIe root 或跨机链路。
  2. 计算梯度 AllReduce 的理论每 rank 通信量。
  3. 从 NCCL 日志判断选用的网络接口、算法和可能的 rank 不一致。
  4. 从时间线判断 overlap 是否真实发生。
  5. 给出从单卡 → 同机两卡 → 同机八卡 → 两机的阶梯复现方案。

任务 6：环境与 ABI

  1. 比较两套环境的 Python、PyTorch、CUDA 构建、编译器、C++ ABI、架构与动态库解析。
  2. 区分“驱动可见”“Toolkit 可用”“框架 CUDA 可用”“扩展 ABI 兼容”。
  3. 解释扩展导入失败属于编译、链接还是运行时装载。

最终交付物

  1. executive-summary.md：一页结论、影响与优先级。
  2. evidence.md：每项事实及来源。
  3. hypotheses.md：假设、支持证据、反证与下一实验。
  4. ledger.md：参数/显存/FLOPs/通信账本。
  5. reproduce.md：最小复现与逐层诊断命令。
  6. patch-plan.md：按风险排序的修复与验证计划。

评分量表

维度分值满分表现
正确性25找到首个错误/非有限点，参考实现与边界测试充分
性能20时间线分解准确，优化与证据匹配
显存账本15包含参数、状态、激活、临时与保留内存
通信20通信量、拓扑、NCCL 与 overlap 分析闭环
环境/ABI10分层准确，能定位装载链
报告质量10事实/推断分离，可复现、可证伪、优先级清楚

禁止做法

  • 未保存原始证据就重装环境。
  • 一次改动多个变量后宣称某项修复有效。
  • 只看平均 GPU 利用率，不看时间线。
  • 只报告“更快了”，不报告输入、预热、重复、分布与正确性。
  • 用最终 loss NaN 代替寻找第一个非有限中间量。

完成后的能力

如果你能独立得到 80 分以上，就已经具备进入 CUDA 算子、分布式训练或推理优化模块的前置能力：不一定会立即写出最快实现，但知道要测什么、怎么算账、怎样验证和怎样缩小问题。
