概念映射

最小语言模型 loss 契约

# input_ids: [B,T]
# targets:   [B,T]，通常是 input 向左移一位后的 next tokens
hidden = model_backbone(input_ids)       # [B,T,H]
logits = lm_head(hidden)                 # [B,T,V]

B,T,V = logits.shape
loss = cross_entropy(
    logits.reshape(B*T, V),
    targets.reshape(B*T),
    ignore_index=pad_id,
)

Attention shape 预告

x                 [B,T,H]
q,k,v projection  [B,T,H]
split heads        [B,heads,T,D]
q @ k.transpose    [B,heads,T,T]
softmax over keys  [B,heads,T,T]
weights @ v        [B,heads,T,D]
merge heads        [B,T,H]

你在 shape 课学到的末轴矩阵乘、permute、broadcast 和 mask，会直接成为 attention 的操作语言。
