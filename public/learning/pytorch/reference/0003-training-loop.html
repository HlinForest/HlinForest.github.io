Training Loop

可复制的骨架、状态读写表、验证协议、故障定位顺序。

背诵forward · loss · zero · backward · step原则先证明链路，再调超参数

最小训练/验证骨架

for epoch in range(epochs):
    model.train()
    for X, y in train_loader:
        X, y = X.to(device), y.to(device)
        logits = model(X)
        loss = loss_fn(logits, y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    model.eval()
    total_loss = total_correct = total_items = 0
    with torch.inference_mode():
        for X, y in val_loader:
            X, y = X.to(device), y.to(device)
            logits = model(X)
            total_loss += loss_fn(logits, y).item() * len(y)
            total_correct += (logits.argmax(-1) == y).sum().item()
            total_items += len(y)
    val_loss = total_loss / total_items
    val_acc = total_correct / total_items
为何 loss 乘 batch size：默认 loss 往往是 batch mean。各 batch 大小可能不同，先还原总和再除总样本数，得到正确的逐样本平均。

五步状态表

调用核心结果
model(X)读取参数，产生输出与图
loss_fn把预测/target 变成优化标量
zero_grad清旧梯度，避免意外累积
backward把新梯度累积到叶参数 .grad
step读取梯度和优化器状态，更新参数

训练不动：按此顺序

  1. 抽样打印 X/y，确认对应关系、范围、类别。
  2. 检查 shape/dtype/device 与 loss 契约。
  3. 检查 logits 是否 finite、是否随输入变化。
  4. 确认参数已注册且 optimizer 持有它们。
  5. backward 后打印 grad None/范数/finite。
  6. 保存 step 前参数副本，断言 step 后发生变化。
  7. 用 8 个样本做 tiny-set overfit。
  8. 最后调 lr、capacity、epochs。
before = {n: p.detach().clone() for n,p in model.named_parameters()}
loss.backward()
for n,p in model.named_parameters():
    print(n, p.grad is None,
          None if p.grad is None else p.grad.norm().item())
optimizer.step()
assert any(not torch.equal(before[n], p.detach())
           for n,p in model.named_parameters())
