0.0 · Tensor manipulation

Einops: a powerful library for tensor operations 推荐

核心主张是用带轴名的模式描述变形，取代一串 `reshape/transpose/squeeze` 和难以审核的整数下标。它的价值不只是少写代码，而是让 shape 语义进入代码本身，从而减少“运行没报错但轴错了”的错误。

Einops basics 必读至 Fancy examples 前

`rearrange` 统一 transpose、reshape、stack/split；括号组合轴，重复轴名禁止出现以避免歧义。`reduce` 把被省略的轴做 sum/mean/max，`repeat` 创建新轴或复制已有轴；模式左右两侧就是可读的 shape 合约。

Einsum is all you need 必读至 2.10

Einstein 记号规定：输入中出现而输出中消失的索引被求和，保留的索引成为输出轴。因此 dot、outer product、transpose、trace、矩阵乘法和 batch matmul 都是同一个规则的实例。ARENA 使用 `einops.einsum` 的具名轴，思维仍相同。

Python pathlib 查阅型

`Path` 把路径当对象组合、遍历与打开，比依赖当前工作目录的裸字符串更跨平台。对 ARENA 的意义是稳定找到 repo root、exercise directory 与数据文件，避免导入和资源路径随启动位置变化。

Using GPT-4 to understand code 推荐

有效流程是给出完整上下文与具体疑问，让模型分段解释，再以运行、测试和文档核验，而不是把第一份解释当真。对学习者最有价值的用法是生成假设、解释陌生抽象和提出最小实验；最终判断仍来自 shape、测试和可观察行为。

0.2 · CNNs & ResNets

ARENA 0.2 配套讲座 章节导入

按“自定义 Module → MNIST 训练 → convolution / pooling → BatchNorm → residual block / ResNet → feature extraction”建立全节路线。讲座的作用是先给结构直觉，练习随后把每个抽象还原成参数注册、shape 变换、状态切换和训练证据；细节以配套讲义与测试为准。

But what is a convolution? 强烈推荐

离散卷积可理解为一个小模式在输入上滑动并做加权汇总；在概率中它组合独立随机变量，在图像中它检测局部模式，在频域中又变成乘法。CNN 实际常做 cross-correlation，但“局部窗口 + 权重共享”的关键直觉不变。

A Comprehensive Guide to CNNs 推荐

按 convolution、activation、pooling、fully connected 的流水线解释 CNN。卷积核逐级从边缘/纹理组合成对象部件，池化降低空间分辨率并提升小位移鲁棒性；适合作为概念图，但实现细节以 PyTorch 文档和 ARENA 为准。

Zoom In: An Introduction to Circuits 延伸

把神经网络解释从单个 neuron 提升为 feature 与 circuit：一个通道的意义取决于它由哪些上游特征构成、又如何影响下游。文章用可视化和 attribution 追踪组合关系，也提醒“单神经元等于单概念”经常过于简单；这是后续机制可解释性的思想桥梁。

Batch Normalization in CNNs 必读

训练时按通道在 batch 与空间轴上规范化，再用可学习 γ/β 恢复合适尺度；推理时使用 running statistics。它改善优化条件、允许更大学习率并带来小批次噪声的弱正则效果。文中的“internal covariate shift”是历史解释，不应视作唯一机制。

Deep Residual Learning for Image Recognition 必读论文

作者发现更深的 plain network 会出现训练误差反而变高的 degradation problem，并改为学习残差 `F(x)=H(x)-x`，输出 `F(x)+x`。identity shortcut 几乎零额外参数，让优化更容易；维度变化用 projection。论文用 34/50/101/152 层网络验证，ResNet 也成为通用视觉骨干。

NumPy as_strided / strides Bonus 前置

stride 表示某轴索引加一时底层存储地址跨多少元素。改变 shape/stride 可以零拷贝得到转置、滑动窗口或重复视图，但也可能产生重叠与越界风险；这解释了高层卷积为何能被还原成“窗口视图 + 求和”。

as_strided and sum are all you need Bonus

展示只靠 `as_strided` 构造广播视图与局部窗口，再用 elementwise product 和 sum 实现 trace、matmul、convolution。关键是从目标索引公式反推每条输出轴对底层地址的贡献；它培养内存布局直觉，不是生产环境重造 BLAS 的建议。

Advanced NumPy stride tricks Bonus

以图示练习覆盖切片、翻转、广播、滑动窗口和 block view。核心训练是同时跟踪 shape、stride、offset；重叠 view 上的写操作可能多次指向同一存储，所以一般只读或先 clone。

0.3 · Optimization & Hyperparameters

ARENA 0.3 配套讲座 章节导入

把优化器看成“读取 gradient、维护 per-parameter state、执行更新”的可替换算法，并把单次训练扩展到记录、对照与超参搜索。主线比较 SGD、momentum、RMSprop、Adam/AdamW，随后连接 W&B、分布式通信和规模化训练的实验方法。

Gradient Descent with Momentum · RMSProp · Adam 强烈推荐

Andrew Ng 的三段视频分别给出：动量对梯度做指数加权平均以减少振荡；RMSprop 对平方梯度做移动平均，以较小步长走陡峭轴、较大步长走平坦轴；Adam 同时使用一阶矩和二阶矩，并对初期的零初始化偏差校正。

A Visual Explanation of Gradient Descent Methods 强烈推荐

用二维轨迹比较 SGD 的抖动、momentum 的惯性、AdaGrad 的累计缩步、RMSprop 的遗忘机制与 Adam 的组合。图像最重要的结论是优化器在不同轴上拥有不同“有效学习率”；算法并非魔法，超参和 loss geometry 仍决定稳定性。

Why Momentum Really Works 可选深读

把二次损失按 Hessian 特征向量分解为互不耦合的一维问题。condition number 大时，同一学习率难以兼顾陡峭与平坦方向；momentum 改变每个方向的动力学，可加速慢方向并抑制快方向振荡。文章也解释了为什么常把 β 设得接近 1。

On Large-Batch Training 正文延伸

超大 batch 虽降低梯度噪声并提高硬件吞吐，却可能收敛到泛化较差的尖锐极小值；训练损失好不等于测试表现好。它纠正“越接近全数据梯度越好”的直觉，并说明 batch size 是优化与泛化共同的超参数。

Decoupled Weight Decay Regularization AdamW

L2 penalty 在自适应优化器中会被逐坐标预条件器缩放，因此不再等同于真正的 weight decay。AdamW 直接在参数更新上做收缩，使 decay 强度与学习率更易独立调节，并改善 Adam 在图像分类上的泛化。

Random Search for Hyper-Parameter Optimization 推荐

当只有少数超参真正重要时，grid search 在不重要维度上浪费试验，而 random search 会探索更多重要维度的不同取值。实践含义是先选合理分布，尤其对学习率用 log scale，再比较多个可复现运行，而非只精调一张网格。

Ring All-Reduce 分布式 Bonus

把张量切成块并沿进程环传递，先 reduce-scatter 再 all-gather，使每个节点都参与带宽而不依赖中心服务器。通信量随 worker 数扩展得更好；正确性来自每块最终遍历所有 worker 并在第二阶段传播完整结果。

Training Compute-Optimal Large Language Models (Chinchilla) Scaling laws Bonus

在固定训练计算量下，模型参数与训练 token 应更均衡地增长；许多早期大模型参数过多、数据不足。论文训练约 70B 参数、1.4T token 的 Chinchilla，优于更大的 Gopher，说明“更大参数量”不是单变量目标，超参调度也会影响 scaling law 结论。

The Optimizer's Curse Bonus

从带噪估计中挑最大值会系统性选择“真实质量高 + 测量误差偏高”的候选，因此最佳验证分数往往高估真实表现。补救是保留独立测试集、嵌套验证、报告不确定性，并减少在同一验证集上的反复决策。

0.4 · Backpropagation

ARENA 0.4 配套讲座 章节导入

从计算图与局部 backward function 开始，逐步加入 recipe、函数注册表、逆拓扑遍历、梯度累积和 broadcasting 的反向，最后组成 Tensor / Parameter / Module / optimizer。它强调本节不是再推一遍链式法则，而是把自动微分落实成软件系统。

Calculus on Computational Graphs: Backpropagation 必读

把复杂表达式拆成原子节点，每条边保存局部导数。前向计算值，反向把上游影响乘局部导数；一条变量到 loss 有多条路径时贡献相加。反向模式自动微分的效率来自共享前向中间量，并在一次逆序遍历中得到一个标量输出对所有参数的梯度。

0.5 · VAEs & GANs

ARENA 0.5 配套讲座 章节导入

用两条生成路线收束 Fundamentals：AE/VAE 通过压缩、重建与分布正则塑造 latent space；GAN 让 generator 与 discriminator 从对抗目标中共同学习。讲座同时预告 transposed convolution、reparameterization、双优化器与训练不稳定，正好复用前面所有 shape、state、gradient、mode 与 evidence 契约。

Understanding VAEs 主线

普通 autoencoder 把样本压到点，潜空间未受约束，空洞和不连续让随机采样失败；VAE 把每个输入映射为潜变量分布，并用 KL 让这些分布靠近统一先验。重建损失保持内容，规则化让潜空间平滑可采样；重参数化把随机采样写成可微参数与独立噪声的组合。

Six (and a half) intuitions for KL divergence 可选深读

KL 可看作使用 Q 编码来自 P 的样本时比最优编码多付的期望信息，也可看作数据平均提供给 P 相对 Q 的证据。它不对称：Q 给 P 常发生的事件近零概率会遭到巨大惩罚。VAE 中方向和期望分布必须写清，不能把 KL 当普通距离。

From Autoencoder to β-VAE 可选深读

系统串联 AE、denoising/sparse/contractive AE、VAE、ELBO、重参数化与 β-VAE。VAE 用 `qφ(z|x)` 近似难算的 posterior，优化重建期望减去与 prior 的 KL；β>1 加强潜变量独立与解耦倾向，但会牺牲重建。

Transposed Convolutions explained with Excel · Convolution arithmetic animations 可选

转置卷积是卷积线性算子的矩阵转置：每个输入值把加权 kernel 写入较大的输出，并非把卷积结果唯一还原成原图。动画直观展示 kernel、padding、stride 如何决定输出大小，也揭示不均匀 overlap 可能造成 checkerboard artifacts。

β-VAE Bonus 论文

在 VAE 的 KL 项前加入 β，增强对信息瓶颈和因子化先验的约束，能在简单生成数据上得到更解耦的潜因子。代价是 reconstruction–disentanglement tradeoff；β 不是越大越好，应同时观察重建与各潜轴分布。

Understanding Diffusion Models: A Unified Perspective Hierarchical VAE 延伸

从 hierarchical VAE 与 ELBO 出发推导 diffusion：多层潜变量对应逐步加噪，反向模型学习逐步去噪；再连接 score matching 与 guidance。对本章的意义是 VAE 的变分推断不是孤立技巧，而是理解现代生成模型的一条入口。

Google GAN course 强烈推荐

区分生成模型与判别模型，拆解 generator、discriminator 及两者相互依赖的训练。原始 minimax loss 在生成器很差时会饱和，实践采用 non-saturating loss；常见问题包括 mode collapse、梯度消失与不稳定，解决需要平衡双方能力与更稳的目标/正则。

DCGAN paper 推荐略读

提出一组稳定训练卷积 GAN 的结构约束：用 stride convolution 代替 pooling、用 transposed convolution 上采样、广泛使用 BatchNorm、generator 用 ReLU 且输出 Tanh、discriminator 用 LeakyReLU。潜空间插值与 learned features 实验说明模型不仅记图，也学到可迁移表示。

How to Train a GAN? / ganhacks 排障清单

经验建议包括把数据缩放匹配 generator 输出、监控真实/生成 batch、使用合适初始化、避免 discriminator 轻易完美、对标签或样本引入温和噪声、持续可视化生成结果。它不是保证收敛的定理，而是定位 GAN 病态的实验检查表。
