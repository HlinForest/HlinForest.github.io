六节逐章梳理

0.0 Prerequisites：先学会深度学习的语言

知识层：神经网络是参数化复合函数；非线性让多层不坍缩为一个线性变换；期望/方差描述随机训练信号；梯度给局部最陡变化；熵、交叉熵与 KL 比较分布。

技能层：使用 `einops.rearrange/repeat/reduce` 和具名轴 `einsum`；熟练 broadcasting、逻辑归约、普通/布尔/整数索引、`gather`；稳定实现 `logsumexp → softmax → logsoftmax → cross entropy`。

通过标准：看到表达式先写每条轴的语义和 shape；能解释 `Tensor / Parameter / Module / loss / optimizer / hyperparameter`；能说出交叉熵为什么接 logits 而不是硬标签。

0.1 Ray Tracing：把循环改写成批量代数

光线写成 O + uD，线段写成 L₁ + v(L₂-L₁)；相交问题等价于解 2×2 线性系统，并检查 u ≥ 0、v ∈ [0,1]。随后把一条 ray 与一个 segment 扩成所有 `(ray, segment)` 组合，用广播构造批量矩阵。

三角形用重心坐标：O + sD = A + u(B-A) + v(C-A)，命中条件是 s≥0, u≥0, v≥0, u+v≤1。mesh 渲染再对所有三角形距离取最小值。

这一节还训练 views/copies、storage、调试器、GPU device、旋转矩阵、法向量与 Lambert 光照；pytest 是奖励内容。

0.2 CNNs & ResNets：第一次真正组装并训练模型

从 `nn.Module` 的参数注册开始，自行实现 ReLU、Linear、Flatten、MLP；用 Dataset / DataLoader / transform 把数据送进模型，再用 `zero_grad → forward → loss → backward → step` 训练，并在 `inference_mode` 下验证。

卷积的核心归纳偏置是局部连接 + 权重共享。核在空间滑动，输出大小为 floor((L+2p-k)/s)+1；多个输出通道代表多个可学习特征检测器，池化负责下采样与保留强响应。

BatchNorm 对每个通道在 batch 与空间轴上规范化，学习 γ/β，并用 running mean/var 服务推理。ResNet 学习 F(x)+x，恒等路径既保留信息又给梯度短路；需要变形时用 projection shortcut。最后复制官方权重验证结构，并冻结骨干对 CIFAR-10 做 feature extraction。

Bonus：`as_strided` 直接操作 shape/stride 的视图，把 trace、matmul、conv 与 maxpool 还原为“取窗口 + 归约”。

0.3 Optimization：梯度有了，怎样走得更快、更稳、更可信

普通 SGD 只用当前梯度；momentum 用一阶指数移动平均抑制狭长谷底中的横向振荡；RMSprop 用平方梯度的移动平均按坐标缩放；Adam 合并两者并做 bias correction；AdamW 把 weight decay 与梯度更新解耦。

课程要求把伪代码翻译成可替换的 optimizer，正确维护每参数 state、原地更新、`zero_grad` 和 parameter groups。W&B 部分把训练代码模块化，记录 config / metrics / gradients / media，用 random 或 Bayesian sweep 搜索学习率、batch size、weight decay 等。

分布式部分从 `send/recv` 组合出 broadcast、reduce、all-reduce，再把每张 GPU 的梯度同步成数据并行训练。概念上区分 data、tensor、pipeline parallelism；实务上理解 rank、world size、backend、blocking、sampler 与 DDP。

0.4 Backprop：亲手搭一个小型 PyTorch

每次前向运算既产生数值，也记录 recipe（函数、输入、参数）。反向从标量 loss 出发，按逆拓扑序把上游梯度乘局部导数；同一节点有多条路径时必须累加。

broadcasting 的反向是 unbroadcast：把广播创造的多条影响路径沿新增或长度为 1 的轴求和。`sum` 的反向相反，要恢复轴再广播。reshape、permute、索引、max、matmul 各有结构化的局部 backward。

最后在 NumPy 上实现 Tensor、Recipe、backward 注册表、`requires_grad/is_leaf`、Parameter、Module、Linear、cross entropy、NoGrad 和 SGD，用自己的系统训练 MNIST。低层细节可参考答案，但 `wrap_forward_fn`、topological order、backprop、梯度累积与 module abstraction 必须真正理解。

0.5 VAEs & GANs：把整章知识用于生成模型

普通 Autoencoder 用 encoder 压缩、decoder 重建，最小化 MSE；但潜空间可能有空洞，随机点未必能解码成有效样本。VAE 的 encoder 输出 μ, log σ，通过 z = μ + σ⊙ε 把随机性移到独立噪声 ε，使梯度可穿过采样。

VAE 损失由重建项与 KL(q(z|x) || N(0,I)) 组成：前者保真，后者让潜空间连续、可采样；β 调整二者权衡。ELBO 是数据对数似然的可优化下界。

GAN 是两个网络的博弈：判别器区分真/假，生成器把噪声变成能骗过判别器的样本。实践使用 non-saturating generator loss 提供早期强梯度，DCGAN 用卷积/转置卷积、BatchNorm、特定初始化和两个 optimizer。只看 loss 不足以判断质量；判别器过强、mode collapse、梯度爆炸和 NaN 都是典型失败。

贯穿整章的五个契约

契约每次都问典型故障
Shape每条轴是什么？哪条被保留、广播或归约？静默广播、通道顺序错、skip 无法相加
State哪些是 parameter、buffer、optimizer state、running stat？参数未注册、BN 推理漂移、动量丢失
Gradient这条边应有梯度吗？多路径是否相加？忘记 detach、梯度累积、生成器被错误更新
Mode现在是 train 还是 eval？是否禁用梯度？验证时 BN 改状态、浪费显存
Evidence什么曲线、样本、基线或复现能说明模型真的工作？只看单个 loss、超参过拟合、数据泄漏
