PyTorch 术语表

课程中的术语以此为准。定义强调实际编程语义，不止是书面翻译。

使用方式复习时先遮住定义自测；编码时用于统一注释语言。更新依据PyTorch 官方文档
术语操作性定义检查方式/例子
Tensor（张量）同一 dtype 的多维数值容器，同时带 shape、device 和 autograd 元数据。x.shape/dtype/device/requires_grad
Axis / Dimension（轴/维）索引结构中的一个方向；应赋予 batch、sequence、hidden 等语义。x.ndim；dim=-1
Shape（形状）每条轴的长度组成的元组。[B,T,H]，不是元素个数
dtype元素数值类型，亦构成 API 语义；类别索引常为 long，网络数值常为 float。torch.float32, torch.long
devicetensor/参数所在计算设备。cpu、cuda、mps；运算两侧须一致
Broadcasting（广播）从末轴对齐，利用长度 1 或缺失轴进行逻辑扩展。[B,T,H]+[H]→[B,T,H]
Logit模型未归一化的 raw score；可为任意实数，通常直接送入稳定组合 loss。二分类 [B]；多分类 [B,C]
Probability（概率）Sigmoid/Softmax 后的 [0,1] 数值；用于解释、阈值、采样。sigmoid(z)/softmax(z,-1)
Target / Label（目标/标签）监督信号；dtype/shape 由 loss 契约决定。BCE: float [B]；CE: long [B]
nn.Module组织 forward、子模块、参数/buffer、模式与设备迁移的基础类。named_parameters(), state_dict()
nn.Parameter被 Module 注册的可学习 tensor，默认需要梯度。出现在 model.parameters()
Buffer（缓冲）随模型保存/移动但通常不被优化器学习的状态。register_buffer
Forward pass（前向）用当前参数从输入计算输出并在需要时构建 autograd 图。logits=model(X)
Computational graph（计算图）一次执行产生的运算依赖图，保存 backward 所需信息。非叶 tensor 的 grad_fn
Autograd（自动微分）按计算图与链式法则计算梯度的引擎。loss.backward()
Leaf tensor（叶张量）通常由用户创建、非其他需梯度运算结果；参数是典型叶子。梯度累积到 .grad
Gradient（梯度）loss 对参数的偏导，给出局部最陡上升方向。p.grad
Optimizer（优化器）读取参数梯度与内部状态，按规则更新参数。SGD、AdamW；step()
Learning rate（学习率）控制更新尺度的关键超参数。过大振荡，过小缓慢
Epoch训练过程完整遍历训练集一次。不同于一个 batch/step
Batch / Mini-batch一次前向/反向处理的样本集合。首轴通常 B
Training modeModule 的训练行为模式。model.train()
Evaluation modeModule 的评估行为模式；不会自动关梯度。model.eval()
Inference mode禁用 autograd 记录的推理上下文。with torch.inference_mode()
state_dict模块参数和持久 buffer 的键值映射。推荐保存单位
Checkpoint用于推理或续训的持久化状态包。可含 model/optimizer/epoch/config
Overfitting（过拟合）训练表现继续改善而未见数据表现恶化/不改善。train–val gap
Underfitting（欠拟合）在链路正确前提下，训练集也拟合不足。训练/验证都差且接近
