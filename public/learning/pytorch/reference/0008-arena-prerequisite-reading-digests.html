数学基础

神经网络 ★★

But what is a neural network?

用 MNIST 建立最小心智模型：神经元持有 activation，层间通过 `Wa+b` 与非线性变换，所有权重与偏置就是从数据中学习的参数。深层网络的希望是逐层形成边缘、部件、类别等层次表示；ReLU 相比饱和 sigmoid 更利于深层梯度传播。

Gradient descent, how neural networks learn

把全部参数看成高维空间坐标，cost 是地形高度；梯度指出局部最陡上升方向，因此沿负梯度小步移动。训练不是“网络突然理解”，而是大量参数微调后让训练样本平均损失下降；学习率决定走得慢、震荡或发散。

What is backpropagation really doing?

一个样本的误差先告诉输出神经元应怎样变化，再沿权重把责任分配给上一层 activation、bias 与 weight。反向传播是链式法则的高效组织：复用中间结果，得到所有参数对 loss 的影响，而非为每个参数重跑网络。

线性代数 ★★

Linear transformations and matrices · Essence of Linear Algebra

矩阵最好先看成空间变换：列向量是基向量变换后的落点，矩阵乘法是函数复合，因此顺序反转。整套系列用几何建立 span、basis、determinant、inverse、rank、eigenvector 的直觉；对深度学习最重要的是 shape、复合与低维子空间。

Matrix–matrix multiplication

`C[i,j] = Σₖ A[i,k]B[k,j]`：共享的 k 轴被归约，外侧 i/j 轴保留。也可把 B 的每一列经 A 变换，或把 A 的每一行与 B 的列做 dot product；这正是 einsum 和 batched matmul 的基础。

Six and a half intuitions for SVD

`M = UΣVᵀ` 把线性映射拆成输入正交方向 V、各方向缩放 Σ、输出正交方向 U。它揭示矩阵保留/丢失哪些信息、最佳低秩近似、PCA 与压缩；在 Transformer 中也可寻找权重作用最强的方向。

Linear Algebra Done Right · Neel Nanda lecture 1 · lecture 2

前者从 vector space、linear map、eigenvalue 到 inner-product 与 spectral theorem，强调结构而不是行列式技巧；两段长课更面向 ML，连接 basis、rank、SVD 与张量运算。当前不必通读教科书，若无法解释线性变换、rank 与 basis 再回补。

SVDs of Transformer weight matrices

研究把 MLP 与 attention 的权重做 SVD，并把主要方向投到 token 空间，发现不少方向形成可解释的语义簇；还可按 token 集自动检索、增强或移除方向。它是探索性结果，不意味着 SVD 已完整解释模型，但展示了基础线代如何进入机制可解释性。

概率、微积分、信息论

Expected value, variance and standard deviation ★★

期望是随机变量长期平均，方差是平方偏差的期望，标准差恢复原单位。期望对任意变量相加；方差只在独立（或协方差为零）时简单相加，一般还要加两倍 covariance。训练中的 minibatch gradient 正是随机估计。

Essence of Calculus ★★

导数是局部变化率，积分是小量累积；偏导描述多变量函数沿单轴变化，gradient 汇总这些方向；chain rule 组合局部变化率。深度学习需要的是能从计算图追踪 shape 与局部导数，而非大量手算积分技巧。

Elements of Information Theory ○ 参考书

建立 entropy、relative entropy、mutual information、source/channel coding 等严格框架。对本章只需掌握：`H(P)` 是 P 自身不可预测性，`H(P,Q)` 是用 Q 编码 P 的平均代价，二者之差是 `KL(P||Q)`；无需当前通读全书。

Six and a half intuitions for KL divergence ★

KL 是错误模型额外造成的期望 surprise/编码长度，也可理解为数据为 P 相对 Q 提供的期望证据。它非负、非对称、不是 metric；当 Q 漏掉 P 可能发生的事件时惩罚可无穷大，这一点直接影响 VAE 和分布拟合。

Python 与数值编程

Intermediate Python（至 for/else） · Python Tutorial ★★

ARENA 期待熟练数据结构、函数、迭代器/生成器、异常、上下文管理器、decorator 与类，而不是只会 notebook 顺序代码。官方教程是语义基准；Python Tips 用短例补充工程惯用法。你 Python 已较熟，可用代码阅读而非逐页复习验收。

100 NumPy Exercises ★★ 实练

覆盖创建、dtype、索引、broadcasting、归约、排序、随机、线代与 stride tricks。价值在于把循环任务改写成 vectorized array program；建议选 20–30 道用 PyTorch 重做，并为每题先写 shape。

PyTorch Learn the Basics ★★

以 FashionMNIST 串起 tensor、Dataset/DataLoader、transform、Module、autograd、optimization loop 与 checkpoint。核心抽象是：Tensor 携带数值与 device/dtype；Parameter 是注册的可训练 Tensor；Module 组织参数和计算；optimizer 读 `.grad` 更新参数。

Einops · Einsum ★

Einops 用左右模式声明轴的拆分、合并、重排、重复和归约；einsum 通过“保留轴/消失轴”统一线性运算。二者共同训练按语义命名轴，而不是靠 `dim=1` 猜测。

Python typing · Plotly · Streamlit ★/○ 工具

typing 让输入输出和可选值成为可检查的接口；jaxtyping 进一步把 tensor dtype/shape 写进注解。Plotly 用于交互曲线、图像和三维可视化，Streamlit 把 Python 分析快速包装成可分享应用；后两者是展示工具，不是深度学习先决条件。

软件工程与环境

Project Euler ★★ 能力基线

用数学与编程结合的问题训练拆解、验证和效率意识。它与 LeetCode 一样不是 ML 教材；若能清晰实现中等难度函数、写测试和处理边界，没必要为了 ARENA 大量刷题。

VS Code Python/Jupyter · Debugger ★★

`# %%` 让 `.py` 同时拥有 cell 式探索与可导入结构；breakpoint、step over/into、watch 与 debug console 比堆 `print` 更适合追踪 shape 和状态。ARENA 鼓励 `.py` 是为了复用、测试和清晰依赖，而不是否定 notebook 探索。

Learn Git Branching · Git/GitHub intro · Git Immersion · Git cheat sheet ★

共同覆盖 repository、commit、branch、merge/rebase、remote、push/pull。交互教程最适合理解 commit graph，长教程适合首次实践，cheat sheet 用于回忆命令；通过标准是能 clone、建分支、stage/commit、同步与恢复可追踪修改。

Getting started with conda ★

环境隔离项目的 Python 与依赖，避免全局包冲突；核心动作是 create、activate、install、export。课程可用 venv/uv/conda 任一方案，重要的是环境可复现，而不是工具宗教。

Berkeley UNIX tutorial · Surrey UNIX tutorial · CS50 terminal setup ○

覆盖文件树、路径、权限、管道、重定向、进程与基本 shell。ARENA 的分布式与远程 GPU 会大量依赖终端；Windows 用户可用 WSL/远程 Linux，但当前 Colab 主线不要求先精通 Unix。

What is torch.nn really?

NLP Demystified

Visualising Representations

神经网络把原始空间逐层扭曲成更易分离的表示；PCA/t-SNE 可以观察高维表示、词向量和句子向量，却需要交互检查局部点与全局结构。可视化既解释模型也暴露数据结构，降维图的轴本身通常没有直接语义。

Spinning Up in Deep RL

David Silver: Introduction to Reinforcement Learning

用 Markov Decision Process 统一预测与控制，后续课程扩展动态规划、Monte Carlo、TD、value approximation 与 policy gradient。经典且严谨，但比 Spinning Up 更长；喜欢视频再选它，不必两套都完整看。

The Matrix Cookbook

矩阵恒等式速查而非教材。ARENA 建议熟悉转置/逆的乘积规则、trace 循环性、determinant 乘法等基本式，并在反向传播时查 vector/matrix derivatives；先懂 shape 再查公式，避免只背符号。

Zoom In: An Introduction to Circuits

见主线摘要。这里作为 0.0 延伸出现，目的是提前看到 feature、direction、circuit 与 attribution 如何把低层视觉表示连成可解释算法。

Why Momentum Really Works

见主线摘要。用 eigenbasis 与 condition number 解释 momentum，不只把它说成“滚下山的球”；最适合在亲手实现 SGD/momentum 后二读。

The Matrix Calculus You Need for Deep Learning

从标量导数规则推广到 vector/matrix，强调 Jacobian shape、elementwise diagonal Jacobian、sum reduction、chain rule 与矩阵乘法求导。其最大价值是“先标 shape 再求导”，可直接服务 0.4 的 matmul、broadcast 与 reduction backward。

A Mathematical Framework for Transformer Circuits

把 Transformer 拆成 residual stream 上可组合的 attention/MLP 路径，并把 attention 写成 QK（决定看哪里）和 OV（决定写什么）电路。通过 path expansion 与小模型案例建立可解释性语言；信息密度很高，应在完成 Fundamentals 与 Transformer 实现后再读。

In-context Learning and Induction Heads

研究两层 attention-only 模型训练时出现的相变，并把 induction head 描述为“在上下文中找到先前相同 token，然后复制其后继”的组合电路。论文提出它们是 in-context learning 的重要机制证据，但不是对所有上下文学习的完整解释。

Neural Networks and Deep Learning — Michael Nielsen

从 MNIST 的 sigmoid network 出发，推导 backprop，解释 cross entropy、regularization、weight initialization、CNN 与深网络训练困难。它把数学、直觉和可运行代码结合得很好；若 3Blue1Brown 太快，可把前两章当系统补课。
