0.1 · Ray Tracing：学习方法、调试与几何

Play in Hard Mode · Play in Easy Mode

两篇用成对隐喻区分两类目标：hard mode 面向长期真实能力，主动暴露弱点、接受失败并防止把代理指标当目标；easy mode 面向明确且有限的胜利条件，允许为过关优化。放进 ARENA 的含义是：练习时应独立推 shape、写测试、查错；但真实工程里该用成熟库和工具，不必为了“从零”制造风险。

Debugger: continue / over / into / out · Debugging in Colab

`continue` 跑到下个断点，`step over` 执行当前语句但不进入函数，`step into` 进入被调函数，`step out` 跑完当前函数返回上层。Colab 可用 Python debugger 在异常处检查 stack、locals 与逐步执行。对张量代码最有效的做法是断在 shape 首次偏离预期的位置，而不是在最终报错处堆 `print`。

Rotation matrices · Lambertian reflectance

三维基础旋转矩阵保持长度与夹角，满足 `RᵀR=I`、`det(R)=1`，绕不同轴旋转的复合顺序通常不可交换。Lambert 漫反射令亮度与单位法向量和光照方向的夹角余弦成正比，即 `max(0, n·l)`；因此 mesh rendering 只需批量求法向、点积和裁零。

mypy

mypy 对 Python type hints 做静态检查，在运行前发现接口类型不一致；类型注解不改变运行时语义。ARENA 结合 jaxtyping 使用时，普通类型说明容器与返回值，shape/dtype 注解说明张量契约，但静态类型不能替代运行时 shape assertions 与数值测试。

0.2 · CNNs & ResNets：实现细节与交叉熵直觉

OrderedDict vs dict

现代 Python `dict` 已保证 insertion order；`OrderedDict` 仍提供 `move_to_end`、从两端 `popitem`、顺序敏感 equality 等专门能力。ARENA 用它组装 `Sequential` 或复制命名层时，重点是模块顺序和名称稳定；一般字典足够，只有显式重排语义时才需要 `OrderedDict`。

Intuitive Explanation of Skip Connections

加法残差连接把 block 写成 `y=F(x)+x`，让恒等映射成为容易达到的基线，并在反向产生一条不经过 `F` 内部 Jacobian 的梯度路径。它缓解深层网络的 degradation 与梯度传播困难；通道或分辨率改变时必须投影 shortcut，使两支 shape 一致。

Intuitively Understanding Cross Entropy · Intuitively Understanding KL Divergence

交叉熵衡量用模型分布 Q 编码真实分布 P 的平均代价；分类时 one-hot P 把它化成正确类别的负对数概率。`H(P,Q)=H(P)+KL(P||Q)`，对固定标签分布最小化交叉熵等价于最小化 KL；KL 非对称，因为“哪些事件由谁采样、用谁编码”有方向。

0.3 · Optimization：证明、搜索、规模与 Muon

Directional derivatives

单位方向 `u` 上的方向导数是 `∇f·u`；由 Cauchy–Schwarz，不改变步长时内积在 `u` 与 gradient 同向时最大，在负梯度方向最小。这证明了 infinitesimal step 的最陡下降方向，但不能保证有限学习率不会越过谷底或在非凸地形找到全局最优。

Setting the learning rate

学习率过小导致进展慢，过大会振荡或发散；训练后期通常降低学习率以在极小值附近精修。learning-rate range test 让学习率从很小逐步上升，观察 loss 开始快速下降与开始爆炸的区间，以此选初值；scheduler 仍应和 batch size、optimizer、训练预算一起记录。

Preventing “Overfitting” of Cross-Validation Data

反复在同一 validation set 上比较大量 hypothesis，会把 validation noise 也纳入选择，候选越多越容易选中偶然乐观者。论文分析这种 model-selection overfitting，并讨论不总选最低 validation error 等策略；现代实践应保留最终 test、限制自适应窥视、报告多 seed 与不确定性。

Hyperband

把超参优化写成资源分配问题：先随机采样许多配置，用小预算试跑，再按 successive halving 淘汰差者，把更多 epoch / data / compute 给有希望者。它能显著减少在失败配置上的浪费，但早期指标若与最终表现相关性弱，也可能过早淘汰“慢热”方案。

Shampoo

Shampoo 针对 tensor parameter 的每条维度维护结构化 preconditioner，而不是展平后保存无法承受的完整二阶矩阵。它利用矩阵逆根近似改变各方向有效步长，可能比一阶法更快收敛；代价是额外 state、矩阵运算与分布式同步复杂度。

Mixed-Precision ImageNet in Minutes

论文组合 mixed precision、大 batch 优化和高效 all-reduce，在大规模 GPU 集群上缩短 ImageNet 训练时间。关键不是只把 dtype 改成 FP16，而是维持数值稳定、调整大 batch 优化并减少通信瓶颈；它展示了 algorithm、numerics 与 systems 必须共同设计。

Muon · Deriving Muon · reference implementation

Muon 面向隐藏层的二维 weight：先计算 SGD momentum，再用 Newton–Schulz iteration 近似把更新正交化，相当于保留梯度更新的 singular vectors、压平 singular values。其几何动机是控制 Linear layer 输出变化；embedding、bias、输入输出层通常仍用 AdamW。结果很有吸引力，但比较必须在调优、公平 compute 与可复现日志下进行。

modded-nanogpt · llm.c GPT-2 reproduction · NanoGPT speedrun worklog

这些 speedrun 记录把固定 validation loss、模型与数据作为终点，系统优化 kernel、precision、batch schedule、optimizer、编译和通信。它们的教学价值是实验必须同时记录 quality 与 wall-clock/compute，并用公开日志和消融证明提升来源；排行榜技巧不能自动推广到所有模型规模。

Scaling Laws curriculum

用 log–log 拟合观察 loss 随参数、数据与计算预算的幂律变化，并强调先定义 irreducible term、受限变量与评估分布。scaling law 用于预算分配和外推，不是自然定律；训练 recipe、tokenizer、数据质量或分布改变都会让旧拟合失效。

Manually classifying CIFAR-10

Karpathy 人工分类小样本得到约 94% 并记录歧义、类别内变化、姿态、局部线索与上下文，说明数据本身限定可达表现，错误不全是优化器问题。文章年代较早、其中 SOTA 数字已过时，但“亲自看错误样本、估计 human/reference baseline”的实验习惯仍重要。

0.4 · Backprop：数值检查与图算法

Finite differences

前向差分 `(f(x+h)-f(x))/h` 近似导数，中心差分通常有更高阶精度。它适合给 autograd 做 gradient check，却不适合作为训练算法：每个参数都要额外 forward，且 `h` 太大会有截断误差、太小会有浮点消减误差。

Topological sorting / Kahn’s algorithm

有向无环图的拓扑序保证每条边的起点先于终点；backprop 需要其逆序，使节点的全部下游梯度贡献先汇总再向父节点传播。Kahn 算法反复取入度为零的节点；DFS postorder 是另一做法。检测 cycle 也能防止错误计算图无限递归。

0.5 · VAE：Gaussian KL 与输入规范化

KL divergence for normal distributions · derivation for two Gaussians

一维 Gaussian 的 KL 可由 log-density ratio 的期望闭式求出；对 diagonal `q=N(μ,diag(σ²))` 与标准正态 prior，逐维项是 `0.5(μ²+σ²-log σ²-1)`。实现常让 encoder 输出 `logvar`，既避免直接约束方差为正，也便于稳定计算 `std=exp(0.5*logvar)`。

Normalization in the MNIST example

`Normalize(mean,std)` 对每通道执行 `(x-mean)/std`；示例常用的常数来自数据集统计而非固定真理。GAN 的 generator 若以 Tanh 输出 `[-1,1]`，真实图片也应缩放到相同范围，否则 discriminator 可利用范围差异作弊。数据变换是模型契约的一部分，必须保存并复用。
