创建

代码用途

rand/randn/randint均匀/正态/整数随机
zeros/ones/full固定初始化
zeros_like(x)沿用 shape/dtype/device
arange(start,end,step)左闭右开序列

变形与拼接

APIshape 规则提示
reshape元素数不变-1 最多一个
unsqueeze(d)插入长度 1 轴[B]→[B,1]
squeeze(d)删除指定长度 1 轴优先指定 d
transpose(a,b)交换两轴可能非 contiguous
permute(order)重排全部轴order 是旧轴编号
stack(xs,d)新增轴输入 shape 相同
cat(xs,d)延长已有轴其他轴相同

广播

从右向左对齐；每对轴相等、其中一个为 1、或某一方缺失。

[B,T,H] + [H]   -> [B,T,H]
[B,T,H] + [T,H] -> [B,T,H]
[B,T,H] + [T,1] -> [B,T,H]
[B,T,H] + [B,H] -> error（通常）

矩阵乘

[m,n] @ [n,p]           -> [m,p]
[B,I] @ [I,O]           -> [B,O]
[B,T,I] @ [I,O]         -> [B,T,O]
[B,H,T,D] @ [B,H,D,T]   -> [B,H,T,T]

nn.Linear(I,O) 接受末轴 I，输出末轴 O；权重实际存储为 [O,I]。
