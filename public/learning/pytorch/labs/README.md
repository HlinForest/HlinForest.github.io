# 实验使用说明

在 `pytorch-foundations` 目录运行：

```bash
python labs/01_tensor_shapes.py
python labs/02_linear_regression.py
python labs/03_multiclass_blobs.py
```

先按每个 `TODO` 上方注释写下预测，再补代码。所有检查通过会打印 `PASS`。至少独立尝试 20 分钟后再查看 `../solutions/`。

依赖只有 PyTorch；绘图不是通过实验的必要条件。安装请使用 [PyTorch 官方选择器](https://pytorch.org/get-started/locally/)。
