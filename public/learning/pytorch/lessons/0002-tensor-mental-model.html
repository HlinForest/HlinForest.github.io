Tensor 不只是数组

把 tensor 看成“数值存储 + 形状语义 + dtype + device + 梯度历史”。训练中任何一项不合约，程序就会报错或悄悄学错。

胜利条件读一行代码便能说出 shape、dtype、device 及是否跟踪梯度。预计时间35–50 分钟主资料LearnPyTorch 00

开场检索

不运行代码，预测下面四个表达式的 ndim 与 shape：

torch.tensor(7)
torch.tensor([7, 7])
torch.tensor([[1, 2], [3, 4]])
torch.zeros(2, 3, 4)
展开答案

分别为：0 与 []；1 与 [2]；2 与 [2,2]；3 与 [2,3,4]。元素个数不是维数；维数是索引一个元素需要的轴数。

Tensor 的四层契约

01

shape
各轴长度，决定运算是否相容。

02

dtype
数值解释与精度，决定 loss/API 是否接受。

03

device
CPU、CUDA 或 MPS；参与同一运算的 tensor 通常必须同设备。

04

autograd 元数据：requires_grad 表示是否追踪与它相关的运算；非叶 tensor 常带 grad_fn；叶参数的梯度累积在 .grad。

Python · 一眼检查四项
x = torch.randn(32, 128, device=device, dtype=torch.float32)
print(x.shape, x.dtype, x.device, x.requires_grad)
# torch.Size([32, 128]) float32 cpu/cuda False

对未来的语言模型，可以把 [32,128] 解读为 [batch, sequence] 的 token ID；经过 embedding 后常成为 [batch, sequence, hidden]。轴名不是 tensor 自带的，但必须存在于你的脑中和注释里。

创建：先问“要表示什么”

意图API要点
从 Python 数据复制torch.tensor(data)通常复制；整数字面量默认推断为整数类型
随机初始化rand/randn/randint均匀 [0,1)、标准正态、离散整数
固定值zeros/ones/full常用于 mask、缓存、初始化
沿用模板属性zeros_like(x)沿用 x 的 shape，通常也沿用 dtype/device
等差序列arange(start,end,step)end 不包含；不要用已弃用的 torch.range
ids = torch.tensor([[10, 23, 7], [9, 2, 0]], dtype=torch.long)
mask = torch.ones_like(ids)          # shape [2, 3], dtype long
weights = torch.randn(3, 8)          # shape [3, 8], float32
image = torch.rand(3, 224, 224)      # [channels, height, width]
dtype 是语义：类别索引与 token ID 通常用 torch.long；网络参数、激活与回归目标通常用浮点。把类别 ID 变成 float 并不会只“多一点精度”，而是违反某些 loss 的输入语义。

运算：逐元素与线性代数不要混

逐元素 *

两边先按 broadcasting 对齐；输出保留广播后的 shape。

[B,H] * [H] → [B,H]

矩阵乘 @

最后两维遵循内维匹配；批维可以广播。

[B,I] @ [I,O] → [B,O]

a = torch.tensor([1., 2., 3.])
print(a * a)   # [1, 4, 9]，逐元素
print(a @ a)   # 14，内积

X = torch.randn(32, 128)
W = torch.randn(128, 256)
b = torch.randn(256)
Y = X @ W + b  # [32, 256]；b 沿 batch 广播

神经网络的线性层本质上是矩阵乘和偏置。PyTorch 的 nn.Linear(in_features, out_features) 接受末轴为 in_features 的输入，并把末轴映射为 out_features。

广播的危险：“代码能运行”不代表语义正确。例如预测为 [B,1]、标签为 [B] 时，某些逐元素运算可能广播成 [B,B]。始终在 loss 前 assert shape。

NumPy 互操作：复制还是共享

import numpy as np

array = np.arange(3, dtype=np.float32)
t1 = torch.from_numpy(array)   # 通常共享底层内存
t2 = torch.tensor(array)       # 复制数据

array[0] = 99
print(t1)  # 第一项通常变为 99
print(t2)  # 保持创建时的 0

back = t1.numpy()              # CPU tensor 可转 ndarray

需要把带梯度的 GPU tensor 交给 NumPy 时，常见安全链是 x.detach().cpu().numpy()：脱离计算图、移到 CPU、再转换。

设备无关代码

device = (
    "cuda" if torch.cuda.is_available()
    else "mps" if torch.backends.mps.is_available()
    else "cpu"
)

model = model.to(device)
X, y = X.to(device), y.to(device)

# .to() 返回新 tensor；不要忘记接住
X = X.to(device)

同一运算的模型参数与数据应在同一 device。调试时打印 next(model.parameters()).device 与 X.device。

可复现性

torch.manual_seed(42)
a = torch.rand(3)
torch.manual_seed(42)
b = torch.rand(3)
assert torch.equal(a, b)

seed 固定随机数流的起点；它不保证不同硬件、算法、库版本都逐 bit 一致。实验报告至少记录 seed、版本、device 和超参数。
