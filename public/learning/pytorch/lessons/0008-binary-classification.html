Logit 不是概率

二分类最重要的不是网络层数，而是把 raw logit、概率、标签和 loss 的接口严格分开。这个习惯会直接迁移到语言模型的词表 logits。

开场检索

模型对 4 个样本输出 [-2.0, 0.0, 1.2, 3.0]。哪些是概率？阈值 0.5 时标签是什么？

答案

这些都是 logits，不是概率。Sigmoid 后约为 [0.119,0.5,0.769,0.953]；若规则是概率 ≥ 0.5 判 1，则标签为 [0,1,1,1]。等价地，logit ≥ 0 判 1。

先写二分类契约

Binary classification contract
对象shapedtype/范围
输入 X[B,F]float
raw logits[B]任意实数 float
target y[B]float，0 或 1
probability[B]float，[0,1]
predicted label[B]0 或 1
class BinaryMLP(nn.Module):
    def __init__(self, in_features):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_features, 16),
            nn.ReLU(),
            nn.Linear(16, 1),
        )

    def forward(self, x):
        return self.net(x).squeeze(-1)  # [B,1] -> [B]
只 squeeze 最后一轴：若用裸 squeeze() 且最后一个 batch 只有一个样本，输出可能从 [1,1] 变成标量 []，破坏 batch 契约。

logits = model(X)                    # 给 loss
probs = torch.sigmoid(logits)        # 给解释/校准/阈值
preds = (probs >= 0.5).float()       # 给准确率/混淆矩阵

# 等价分类边界（阈值恰为 0.5 时）
preds_fast = (logits >= 0).float()

阈值不一定永远是 0.5。类别不平衡或误判成本不同，应在验证集上根据 precision/recall 等目标选择，而不是在测试集上挑到最好看。

为什么用 BCEWithLogitsLoss

二元交叉熵为：

L = −[y log σ(z) + (1−y) log(1−σ(z))]

官方文档指出，BCEWithLogitsLoss 把 Sigmoid 与 BCE 合并，利用 log-sum-exp 技巧提升数值稳定性。因此：

loss_fn = nn.BCEWithLogitsLoss()
logits = model(X_train)
loss = loss_fn(logits, y_train)   # 正确：传 raw logits
# 错误组合：重复 sigmoid
loss = loss_fn(torch.sigmoid(logits), y_train)

重复 Sigmoid 不仅接口错，还压缩了输入范围和梯度。记忆规则：loss 名称里有 WithLogits，就给 logits。

类别不平衡：pos_weight 可提高正类损失权重，但它不是“万能修复”。仍要明确采样分布、指标、阈值和真实业务代价。

二分类训练循环

loss_fn = nn.BCEWithLogitsLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

for epoch in range(epochs):
    model.train()
    logits = model(X_train)
    assert logits.shape == y_train.shape
    loss = loss_fn(logits, y_train)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    model.eval()
    with torch.inference_mode():
        val_logits = model(X_val)
        val_loss = loss_fn(val_logits, y_val)
        val_pred = (val_logits >= 0).float()
        val_acc = (val_pred == y_val).float().mean()

训练指标的预测转换不参与反传；真正梯度路径是 logits → BCEWithLogitsLoss。阈值/round 是不可导的，也无需进入 loss。
