Shape error 是深度学习最常见的错误之一。真正的能力不是反复试 squeeze()，而是给每个轴命名、推导契约、只做有语义的变换。

轴名变形广播矩阵乘调试检查

开场检索：只允许纸笔

已知 X:[32,128,768]，代表 [batch,sequence,hidden]；W:[768,3072]。预测 X @ W shape。

答案

[32,128,3072]。矩阵乘只替换末轴：hidden 768 与 W 的输入维匹配，批维 [32,128] 保留。这正是 Transformer 中 projection 的常见形状。

第一原则：shape 必须带轴名

[32,128,768] 本身信息不足；写成 [B,T,C] 才能推理：

轴意义改变它意味着什么
Bbatch size同时处理多少样本
Tsequence length每个样本有多少 token/时间步
C 或 Hchannel/hidden每个位置的表示维数
建议：在每个关键 tensor 旁写注释，例如 # logits: [B, C]；在模块边界用 assert 把假设变成可执行契约。
def forward(self, x):
    # x: [B, T, H]
    assert x.ndim == 3
    assert x.shape[-1] == self.hidden_size
    return self.proj(x)  # [B, T, V]

变形工具：每个动作回答一个问题

操作是否改变元素数是否新增/删除轴典型意图
reshape(...)否可重组合并 batch 与 time；恢复结构
view(...)否可重组共享 storage 的 view；受连续性限制
unsqueeze(dim)否新增长度 1 轴[B]→[B,1]
squeeze(dim)否删除指定长度 1 轴[B,1]→[B]
transpose(a,b)否交换两轴[B,T,H]→[B,H,T]
permute(...)否重排所有轴显式指定新轴顺序
stack(xs,dim)增加创建新轴N 个 [H] → [N,H]
cat(xs,dim)增加不创建新轴沿已有轴拼长
x = torch.arange(24).reshape(2, 3, 4)  # [B=2, T=3, H=4]
flat = x.reshape(6, 4)                  # [B*T, H]
restored = flat.reshape(2, 3, 4)       # [B, T, H]
channels_first = x.permute(0, 2, 1)    # [B, H, T]
不要裸用 squeeze()：当 batch size 恰好为 1，它会把 batch 轴也删掉。若只想去掉二分类输出的末轴，用 squeeze(-1)。

Broadcasting：从右向左对齐

比较两个 shape 时，从末轴向前；每对轴必须相等，或其中一个为 1，或某一方没有该轴。

[B,T,H] + [H] → [B,T,H]
[B,T,H] + [T,1] → [B,T,H]
[B,T,H] + [B,H] → 通常不相容

位置编码常以 [T,H] 加到 token 表示 [B,T,H] 上：缺失的 B 轴被视作 1，然后沿 batch 广播。

tokens = torch.randn(32, 128, 768)  # [B,T,H]
pos = torch.randn(128, 768)         # [T,H]
x = tokens + pos                    # [B,T,H]

广播节省了显式复制，但也会掩盖标签 shape 错误。loss 前建议：

assert logits.shape == targets.shape, (logits.shape, targets.shape)

Matmul：只盯住最后两轴

对二维矩阵，[m,n] @ [n,p] → [m,p]。对更高维，最后两轴做矩阵乘，前面的轴按 batch broadcasting 处理。

表达式结果理由
[B,I] @ [I,O][B,O]普通批量线性层
[B,T,I] @ [I,O][B,T,O]每个 token 共用同一投影
[B,H,T,D] @ [B,H,D,T][B,H,T,T]attention score 的典型 shape

线性层的权重方向

nn.Linear(I,O) 的权重存储 shape 是 [O,I]，forward 内部效果为 x @ weight.T + bias，所以输入末轴仍须为 I，输出末轴为 O。

五步 Shape 调试法

1. 写语义
为每个轴命名，不接受裸数字。
2. 写期望
在运行前推导输出 shape。
3. 查边界
打印/断言进入模型、离开模型、进入 loss 三处。
4. 找首个偏差
第一处偏离契约的位置才是根因；后续报错往往只是症状。
5. 做最小变换
只在你能解释轴语义时 reshape/squeeze/transpose。
print("X", X.shape, X.dtype, X.device)
print("logits", logits.shape, logits.dtype, logits.device)
print("y", y.shape, y.dtype, y.device)
assert logits.shape[0] == y.shape[0]
assert logits.device == y.device

出口检查

纸笔 shape 推导

1. [32,128,768] @ [768,3072] 的结果是？
2. 二分类 logits 为 [B,1]，最稳妥变为 [B]？

答案与理由

1：[32,128,3072]。2：squeeze(-1) 只删除末轴，保住可能为 1 的 batch 轴。
