开场检索：先别查资料

用你现在的理解，各写一句话：

  1. 模型训练时，数据怎样最终改变一个 weight？
  2. 为什么把很多 Linear 层叠起来仍需要 activation？
  3. 训练 loss 下降，能否证明模型已经学会泛化？
写完后再看判断标准

合格答案应出现这条链：数据 → forward → logits/prediction → loss → backward 得到 gradient → optimizer 更新 parameter；多层纯线性变换仍可合并为一个线性变换；训练集 loss 只说明对已见数据的拟合，还需要独立验证、正确模式与可复现实验证据。

训练的最小闭环并不神秘：模型用参数做前向计算，损失把预测与目标压成一个标量，自动微分算出每个参数对损失的局部影响，优化器再依据这些梯度更新参数。ARENA 的安排让你从会调用这台机器，逐渐走到能拆开并重做它。

贯穿课程的五个检查词：shape、state、gradient、mode、evidence。以后遇到 bug，先按这五类定位，而不是立刻换模型或乱调学习率。

0.1 看似离深度学习最远，却专门训练最常见的底层瓶颈：批量维、广播、数值边界和调试。0.4 放在优化之后也有意为之：先观察框架怎样用 gradient，再亲手实现 gradient 怎样被算出来。

起点诊断：只标“独立能做”

不要按“看过/听懂”打勾；只有不查模板也能解释或实现，才算通过。

A · 张量语言

能预测 [B,T,D] @ [D,H] 的输出；能解释 broadcast；能用 einsum 写 batch dot product。

B · 训练闭环

能从空文件写 Dataset/DataLoader、Module、loss、optimizer、train/eval 与 checkpoint。

C · 梯度机制

能画计算图，用 chain rule 求导，并解释共享变量的梯度为何相加。

D · 实验证据

能区分 train/validation/test，固定随机性，并由曲线判断欠拟合、过拟合或发散。

按你的已知背景，默认从 B 的训练闭环开始。你会 Python、能做理论推导，但还没有独立训练经验。最近发展区不是先啃完整数学书，而是先让一条训练链可靠跑通，再用 0.0 与 0.4 把 shape 和 gradient 理解补实。

五分钟终检

六节是否已经连起来？

1. 光线追踪最主要迁移到模型训练的能力是什么？
2. Adam 相比裸 SGD 额外维护的关键是什么？
3. broadcasting 的反向核心动作是什么？
4. VAE 与 GAN 的生成约束分别主要来自哪里？

答案与理由

1：光追是 batched tensor 训练场。2：moment estimates 等 optimizer state。3：广播复制了一条影响路径，反向要沿这些轴累加。4：VAE 用 reconstruction + KL，GAN 用 discriminator 提供的对抗训练信号。
