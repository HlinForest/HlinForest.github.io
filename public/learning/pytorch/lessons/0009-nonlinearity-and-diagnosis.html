为什么堆线性层仍是线性

当训练链路正确、loss 仍停滞时，问题可能不是优化，而是表示能力。用圆环分类看见激活函数如何改变函数族。

开场检索

没有激活函数的两层线性网络 f(x)=W₂(W₁x+b₁)+b₂ 是否比一层线性函数能表达更多形状？先写代数。

答案
f(x)=(W₂W₁)x+(W₂b₁+b₂)=W′x+b′

仍是一个仿射变换。增加参数化方式不等于增加非线性表达能力。

线性分类器只能画超平面

二分类模型若 logit 为 z=wᵀx+b，0.5 概率阈值等价于 z=0，决策边界是一条直线（高维中为超平面）。同心圆、XOR 等数据不能被一条直线分开。

诊断信号：训练和验证准确率都卡在相似的低水平，梯度正常、参数在变、不同 lr 结果相近，同时决策边界明显过于简单——这才支持“容量/函数族不足”。

ReLU 把空间切成分段线性区域

ReLU(x)=max(0,x)
class NonlinearBinaryMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 16),
            nn.ReLU(),
            nn.Linear(16, 16),
            nn.ReLU(),
            nn.Linear(16, 1),
        )

    def forward(self, x):
        return self.net(x).squeeze(-1)

每个 ReLU 根据 pre-activation 正负选择不同分支；多个神经元组合出许多局部线性区域，从而近似弯曲边界。输出层不加 Sigmoid，因为 BCEWithLogitsLoss 接 raw logits。

亲手复刻激活函数

def manual_relu(x):
    return torch.maximum(x, torch.tensor(0., device=x.device))

z = torch.linspace(-3, 3, 7)
torch.testing.assert_close(manual_relu(z), torch.relu(z))

“改进模型”的四个旋钮

旋钮改变什么风险
宽度每层特征数/局部模式数量参数和过拟合增加
深度函数复合层级优化更复杂
非线性可表达函数族不当激活/初始化影响梯度
训练预算/lr能否找到好参数不能修复错误函数族或数据

一次只改变一个变量并记录实验；否则性能变化无法归因。固定 seed 有助于公平比较，但最好用多个 seed 判断稳健性。

欠拟合、过拟合还是实现错误？

实现错误

小样本也拟合不了；梯度 None/NaN；参数不变；shape 契约异常。

欠拟合

链路正常；训练/验证都差且接近；增加合适容量后改善。

过拟合

训练很好、验证变差；差距随训练扩大。

分布问题

验证与训练差异来自采样、漂移或泄漏；加模型未必解决。
