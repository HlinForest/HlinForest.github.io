训练结束，不等于工作结束

可靠的模型必须能切换到推理语义、保存状态、在新进程重建，并证明重载后的输出一致。

胜利条件保存 state_dict，重建模型，严格加载并验证预测一致。预计时间30–45 分钟主资料LearnPyTorch 01 · Save/load

开场检索

model.eval() 和 torch.inference_mode() 是重复的吗？各控制什么？

答案

不重复。eval() 切换模块行为（如关闭 Dropout、让 BatchNorm 用运行统计）；inference_mode() 关闭 autograd 记录并减少推理开销。可靠推理通常同时使用。

推理协议

model.eval()
with torch.inference_mode():
    logits = model(X_new.to(device))

# 若交给 NumPy/绘图库
logits_np = logits.detach().cpu().numpy()

推理输入必须使用与训练一致的预处理、特征顺序、归一化、tokenizer 和类别映射。checkpoint 只保存权重而不保存这些语义时，应另存配置。

反例：训练使用标准化输入，部署直接输入原始数值。模型文件成功加载、代码不报错，但预测语义已损坏。这类 silent bug 比 shape error 更危险。

优先保存 state_dict

from pathlib import Path

path = Path("models/linear_state.pt")
path.parent.mkdir(parents=True, exist_ok=True)
torch.save(model.state_dict(), path)

state_dict 是参数与持久 buffer 的键值映射。它与 Python 类定义分离，通常比序列化整个 model 对象更可移植、更明确。

for key, value in model.state_dict().items():
    print(key, tuple(value.shape), value.dtype)

重建架构，再加载权重

loaded_model = LinearModel().to(device)
state = torch.load(path, map_location=device, weights_only=True)
loaded_model.load_state_dict(state, strict=True)
loaded_model.eval()

如果当前 PyTorch 版本不支持 weights_only 参数，查阅当前官方文档并按版本调整。对不可信 checkpoint 要格外谨慎；不要把任意外部文件当作安全数据执行。

最重要的验收：预测一致

model.eval()
loaded_model.eval()
with torch.inference_mode():
    before = model(X_test)
    after = loaded_model(X_test)

torch.testing.assert_close(before, after)
print("reload verified")

只看到“load 成功”还不够；预测一致才证明保存—重建—加载链路闭合。

恢复训练需要更完整的 checkpoint

torch.save({
    "epoch": epoch,
    "model_state": model.state_dict(),
    "optimizer_state": optimizer.state_dict(),
    "config": {"lr": 0.1, "seed": 42},
    "train_loss": train_loss.item(),
}, "models/train_checkpoint.pt")

若要无缝续训，还可能需要 scheduler、随机数状态、混合精度 scaler、数据 sampler 状态。仅做推理时，模型权重 + 明确配置通常更轻。

保存内容按目的选择
目的最低内容加载后
只做推理model state + 架构/预处理配置eval + inference_mode
继续训练model + optimizer + epoch + 超参数恢复状态后 train
复现实验以上 + seed/版本/数据版本/代码版本验证指标与预测
