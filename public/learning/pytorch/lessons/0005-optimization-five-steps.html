训练 Step 的五个动词

forward、loss、zero、backward、step。关键不在背诵，而在准确说出每一步读取什么、写入什么，以及顺序错了会发生什么。

胜利条件闭卷重写一次参数更新，并跟踪 parameter/value/grad 状态。预计时间35–50 分钟主资料LearnPyTorch 01 · Train model
五步状态追踪五步模拟LossOptimizer检查

开场检索

先闭卷写五行训练核心。提示：第一行产生预测，最后一行改变参数。

答案
y_pred = model(X)
loss = loss_fn(y_pred, y)
optimizer.zero_grad()
loss.backward()
optimizer.step()

zero_grad() 放在 backward 之前即可；常见写法是每个 step 的开始。不能放在 backward 与 step 之间，否则优化器读到的是空梯度。

五步不是咒语，是数据流

步读取写入/产生若漏掉
1 model(X)X、当前 θ预测/计算图没有模型输出
2 loss_fn(...)预测、y标量 loss/计算图无优化目标
3 zero_grad()旧 θ.grad清空/设 None梯度跨 step 累积
4 loss.backward()计算图θ.grad += ∂L/∂θ没有新梯度
5 optimizer.step()θ、θ.grad、优化器状态更新 θ 与可能的动量状态参数永不学习
一句话：backward 计算“往哪走、多陡”；optimizer 决定“怎样走、多远”。

对一次 SGD 做状态追踪

设 w=1，梯度 ∂L/∂w=−12，学习率 η=0.1：

w_new = w_old − η·grad = 1 − 0.1×(−12) = 2.2
w = torch.tensor([1.0], requires_grad=True)
optimizer = torch.optim.SGD([w], lr=0.1)

loss = (w * 2 - 5).pow(2).mean()
optimizer.zero_grad()
loss.backward()
print("before step:", w.item(), w.grad.item())  # 1.0, -12.0
optimizer.step()
print("after step:", w.item(), w.grad.item())   # 2.2, -12.0
流程模拟器

观察五步各自读写什么

1forward读 X、w
2loss写标量目标
3zero_grad清旧梯度
4backward写 w.grad
5step更新 w
parameter w
w.grad
prediction ŷ
loss L

观察：step() 更新参数，但不会自动清掉梯度。下一轮的 zero_grad() 负责清理。现代 PyTorch 常把 grad 设为 None，而非填零；语义仍是阻止意外累积。

为什么不能在 step 前清梯度？

loss.backward()
optimizer.zero_grad()  # 把刚算好的梯度清掉
optimizer.step()       # 无梯度可读，参数不更新

选择 Loss 是定义任务接口

任务模型输出标签常用 loss
回归[B,1] 或 [B] float同 shape floatMSELoss/L1Loss
二分类[B] raw logits[B] float 0/1BCEWithLogitsLoss
单标签多分类[B,C] raw logits[B] long 类别索引CrossEntropyLoss

Loss 通常直接接 raw logits，因为组合实现更数值稳定。展示概率与计算 loss 是两条不同路径：loss 路径保留 logits；解释预测时才 Sigmoid/Softmax。

优化器与学习率

torch.optim.SGD 足以理解训练；Adam/AdamW 会维护一阶、二阶动量状态，但仍读取 .grad 并更新参数。

loss_fn = nn.L1Loss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for epoch in range(100):
    model.train()
    y_pred = model(X_train)
    loss = loss_fn(y_pred, y_train)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

学习率过大

loss 振荡、爆炸或变 NaN；参数跨过谷底。

学习率过小

loss 下降极慢；有限训练预算内像“学不会”。

调参前先确认基本链路正确：数据/标签对应、shape、loss 契约、参数已注册、梯度非 None、step 后参数确实改变。

故障判断

训练为何不动

1. backward 后立刻 zero_grad，再 step；参数不变的原因？
2. 每轮都 backward 但从不 zero_grad，发生什么？

答案

1：梯度已经清空。2：梯度默认累积。
