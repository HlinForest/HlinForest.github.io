从 C 个类别到 V 个 Token

多分类把模型输出扩展为每个类别一个 logit；语言模型只是把类别数扩大到词表大小，并在每个序列位置重复这件事。

胜利条件独立训练多分类器，并把 shape 契约迁移到 next-token prediction。预计时间60–90 分钟主资料LearnPyTorch 02 · Multiclass实践Lab 03
多分类契约Softmax训练LLM 桥梁挑战终检

开场检索

4 类任务，batch size 32。模型 logits 与类别索引 target 各是什么 shape/dtype？CrossEntropyLoss 前要不要 Softmax？

答案

logits 为 [32,4] float；target 为 [32] long，每项在 [0,4)。loss 前不要 Softmax，直接传 raw logits。

多分类契约

Single-label multiclass contract
对象shapedtype/含义
X[B,F]float features
logits[B,C]float，每类一个 raw score
target[B]long，类别索引 0…C−1
probabilities[B,C]softmax 后每行和为 1
prediction[B]argmax(dim=1)
class MulticlassMLP(nn.Module):
    def __init__(self, in_features=2, hidden=16, classes=4):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_features, hidden),
            nn.ReLU(),
            nn.Linear(hidden, classes),
        )

    def forward(self, x):
        return self.net(x)  # [B,C]

Softmax：把相对分数归一化

pᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)
logits = model(X)                       # [B,C]
probs = torch.softmax(logits, dim=1)    # [B,C]
pred = probs.argmax(dim=1)              # [B]

# 只要类别标签，不需要显式 softmax：
pred_fast = logits.argmax(dim=1)

argmax 在单调变换 softmax 前后相同。需要置信度/概率分布时才显式 softmax；训练 loss 仍接 logits。

dim 要有语义：对 [B,C]，类别轴是 1；对语言模型 [B,T,V]，词表轴是 −1。沿 batch 做 softmax 会让不同样本互相归一化，语义完全错误但可能不报错。

多分类训练核心

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for epoch in range(200):
    model.train()
    logits = model(X_train)              # [B,C]
    assert y_train.dtype == torch.long
    loss = loss_fn(logits, y_train)       # target [B]

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    model.eval()
    with torch.inference_mode():
        val_logits = model(X_val)
        val_loss = loss_fn(val_logits, y_val)
        val_pred = val_logits.argmax(dim=1)
        val_acc = (val_pred == y_val).float().mean()

CrossEntropyLoss 在常见类别索引用法中等价于 log-softmax 与负对数似然的稳定组合。不要把已经 softmax 的概率传进去。

评估要看每一类

整体 accuracy 可能掩盖少数类失败。至少查看 confusion matrix、每类 precision/recall 和数据支持量；类不平衡时可使用 class weight，但应记录权重来源。

把分类 shape 提升一个序列轴

普通多分类语言模型 next-token
输入 [B,F]token IDs [B,T]
隐藏表示 [B,H]embedding/hidden [B,T,H]
logits [B,C]vocab logits [B,T,V]
target [B]next-token IDs [B,T]
在 C 轴分类每个 T 位置在 V 轴分类
# logits: [B,T,V], targets: [B,T]
B, T, V = logits.shape
loss = nn.CrossEntropyLoss(ignore_index=pad_id)(
    logits.reshape(B * T, V),
    targets.reshape(B * T),
)

# 预测每个位置的 token id
next_token_ids = logits.argmax(dim=-1)  # [B,T]
核心迁移：每个 token 位置都是一个 V 类分类问题，共享同一个语言模型。Embedding、attention 会改变隐藏表示的生成方式，但 logits/loss/反传/优化的主链与本课相同。

语言模型中新增的复杂度

  • padding/causal mask 决定哪些位置参与 attention 或 loss；
  • 序列很长，显存与计算成为一等约束；
  • 权重共享、残差、归一化和注意力丰富了模型结构；
  • 混合精度、梯度累积、裁剪、分布式训练改变工程规模，但不改变基本状态机。
