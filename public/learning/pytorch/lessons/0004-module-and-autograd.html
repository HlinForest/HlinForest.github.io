开场检索

函数 ŷ = wx + b，L = (ŷ − y)²。若 x=2、y=5、w=1、b=0，求 ∂L/∂w 和 ∂L/∂b。

答案

ŷ=2，误差 −3。∂L/∂ŷ=2(ŷ−y)=−6；∂ŷ/∂w=x=2，故 ∂L/∂w=−12；∂ŷ/∂b=1，故 ∂L/∂b=−6。负梯度意味着一次梯度下降会增大 w、b，使预测向 5 靠近。

import torch
from torch import nn

class LinearRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(1))
        self.bias = nn.Parameter(torch.randn(1))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.weight * x + self.bias

model = LinearRegressionModel()
print(list(model.named_parameters()))
print(model.state_dict())
y_hat = model(torch.tensor([2.0]))  # 调用 model(...)，不要手调 forward

通常优先组合现成层：

class BetterLinearModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(in_features=1, out_features=1)

    def forward(self, x):
        return self.linear(x)
注册陷阱：把普通 tensor 放在 self.foo 上不会自动成为可学习参数。需要学习就用 nn.Parameter；需要随模型保存和移动但不学习的持久 tensor，可用 register_buffer。

链式法则
x = torch.tensor([2.0])
y = torch.tensor([5.0])
w = torch.tensor([1.0], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

y_hat = w * x + b
loss = (y_hat - y).pow(2).mean()
print(y_hat.grad_fn)  # AddBackward...
print(loss.grad_fn)   # MeanBackward...

loss.backward()
print(w.grad, b.grad) # tensor([-12.]), tensor([-6.])
流程模拟器

一条梯度怎样回到参数

叶 tensorx, y, w, b

标量目标L = (ŷ−y)²
局部反向∂L/∂ŷ上游梯度
叶梯度w.grad, b.grad

图保存了 backward 所需的中间信息。默认一次 backward 后图会释放；若无充分理由，不要加 retain_graph=True 来压住错误。

叶子、非叶子与梯度累积

对象典型例子.grad
需要梯度的叶 tensor用户创建的 w；Module Parameterbackward 后累积梯度
非叶 tensory_hat、loss默认不保留；有 grad_fn
不需梯度 tensor输入 X、标签 y（通常）不记录与自身有关的梯度
loss.backward()
first = w.grad.clone()

# 再建一张图并 backward，但没有清空 w.grad
loss2 = ((w * x + b) - y).pow(2).mean()
loss2.backward()
assert torch.equal(w.grad, first * 2)  # 梯度累积

累积不是 bug：梯度累积可模拟更大 batch。但常规每 step 更新一次时，必须显式清零。

三件容易混淆的事

机制改变什么不改变什么
model.eval()Module 的训练/评估行为不会自动关闭 autograd
torch.inference_mode()关闭梯度记录并优化推理开销不会自动调用 model.eval()
tensor.detach()返回与当前图断开的 tensor不会把模型切换到评估模式
model.eval()
with torch.inference_mode():
    predictions = model(X_test)

# 恢复训练时
model.train()

在线性层这个小例子中 train/eval 输出相同，但养成完整习惯很重要：未来含 Dropout/BatchNorm 时，模式会改变结果。
