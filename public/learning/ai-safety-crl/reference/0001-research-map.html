Reference 01

AI Safety × CRL 研究地图

快速判断你正在解决的是变量、结构、效应、决策还是资源分配问题。

打印友好术语 + 假设 + 失败模式

一条主链

高维观测 X → 可识别表示 V̂ [Yujia 邻近：什么能恢复？] → 候选因果结构 G_adv [结构学习：哪些边仍不确定？] → 主动干预 / 验证 [Davin 邻近：下一次试什么？] → 风险信号 / advice [建议会有多错？] → 安全资源策略 π [有限预算 + 对手最佳响应]

五个常被混淆的输出

输出它回答什么它不自动保证什么
低重构误差latent 保留了观测信息坐标有真实因果语义
任务充分表示保留了预测/控制任务所需信息恢复全部真实因果变量
部分 disentanglement目标组不混入指定外部因素组内逐坐标唯一
结构等价类哪些图与数据/假设兼容所有边方向都已确定
风险排序哪些样本更值得审查适应性对手下仍最优

研究者定位

安全接口产生更可信的风险概念验证概念并分配有限监督资源

四卡模板

Input: 已知什么？数据来自几个环境？变量是否已定义？建议从哪里来？ Output: 要恢复什么？latent、子空间、DAG、effect、policy，还是 audit allocation？ Cost: 最小化什么？samples、interventions、rounds、人类分钟数或部署风险？ Guarantee: 在哪些假设下，对 identifiability、error、regret 或 worst case 给什么界？

最小假设审计

  • 共享观测机制：跨域改变的是 latent 机制，还是相机/tokenizer/模型层本身？
  • 变化充分：环境很多，还是独立变化方向真的很多？
  • 干预目标：命中指定变量，还是可能 off-target？
  • 有限样本：理论识别是否在当前噪声、样本量与模型错设下可检测？
  • 建议误差：如何定义与测量 advice quality？何时触发回退？
  • 适应对手：风险分布会不会根据公开审计策略改变？

失败模式 → 修复动作

看到什么可能原因下一步
重构好，干预乱latent 可逆混合加入配对环境、负对照、自然干预
跨域不稳mixing 也变了校准传感器/模型层，显式建模域特定 mixing
多个环境仍不识别变化方向重复、秩不足主动选择机制差异更大的环境
建议好时没收益算法过度保守提高 consistency，先验证关键子集
建议坏时崩溃缺少回退/覆盖保留随机探索与无建议基线
固定审计被绕过忽略策略性响应随机化覆盖，使用 Stackelberg 视角

一句话自测

  1. 能否构造 V'=q(V), f'=f∘q⁻¹ 并解释重构为何不变？
  2. 能否说出“更多样本”和“更多识别信息”的区别？
  3. 能否准确区分 latent identifiability、causal discovery 与 effect estimation？
  4. 能否解释好 advice 时受益、坏 advice 时回退的双目标？
  5. 能否写出一个会证伪自己研究主张的结果？
