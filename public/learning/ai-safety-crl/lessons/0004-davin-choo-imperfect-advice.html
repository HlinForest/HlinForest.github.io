三节点例子：观测数据留下多个方向

安全团队记录三个变量：A 可疑训练样本比例、B 监控器告警、C 部署后失效。观测条件独立关系可能只支持一条无碰撞点链：

A → B → C A ← B → C A ← B ← C 三者可属于同一 Markov 等价类：仅凭观测不能定向全部边。

一个领域专家或预训练模型给出建议图 G_adv。它可能非常接近真实图，也可能系统性误解告警与失效的方向。主动学习器应先验证最能区分候选图的部分，再决定是否继续沿建议搜索。

“带建议算法”的两个目标

Consistency

建议接近真实时，明显少做干预、少花成本；不能因为防最坏情况而完全忽略高质量建议。

Robustness

建议任意错误时，性能仍接近无建议基线；不能让一次自信但错误的图把成本推到失控。

ICML 2023 的正式结果用 advice DAG 与真实 DAG 的距离 ψ 描述这种自适应收益，并保留与无建议方法相当的最坏情形保证。下面是为了建立直觉而设计的简化玩具，不是论文定理数值复现。

安全监控器就是“不完美建议”

一个因果/可解释特征系统给每条模型轨迹打风险分。最危险的做法是把它当真值：只审查高分轨迹。攻击者一旦学会绕过特征，所有资源都被引向假目标。

更稳健的策略会把分数当建议：高分区加权抽查，同时保留随机覆盖、负对照与触发式回退。建议准确时节省预算；校准恶化或出现冲突时，退回与建议无关的安全基线。

从算法建议到 Stackelberg 安全博弈

2026 年的 Incentive-Aware AI Safety 把监督看成 defender 与能观察策略的 attacker/失效模式之间的战略互动。关键变化是：风险不是静态分布；对手会针对你最薄弱的覆盖。

“监控器 AUC 更高，所以把全部审计预算给最高分样本一定更安全。”

AUC 是静态排序指标。若攻击者或失效模式会适应审计策略，确定性全押可能创造完全裸露的目标；还要考虑校准漂移、覆盖、对手最佳响应与回退保证。

读 Davin 论文时用四卡

Input: 已知什么？（essential graph / advice DAG / samples） Output: 恢复什么？（true DAG / effect / policy） Cost: 最小化什么？（interventions / rounds / regret / audit budget） Guarantee: 对什么量给界？（advice distance / worst case / estimation error）

Davin Choo 的官方定位包括 statistical learning、causal inference、imperfect advice 与 resource-efficient algorithms。ICML 2023 论文正式研究带 advice 的主动因果结构学习；AAMAS 2026 Blue Sky 论文把 Stackelberg security games 引入训练时审计、部署前评测和多模型部署。把 CRL 特征作为 advice 输入是本课程的桥接设想，不是两篇论文已经共同证明的定理。
