20 分钟Capstone产出：mini-proposal
本课胜利条件：你能完成一张 Input / Output / Cost / Guarantee 四卡，并列出至少一个会推翻自己方案的结果。

一个完整案例：会操作网页的 agent

一个 browser agent 能读取邮件、提交表单和修改账户设置。安全团队担心它在含糊授权下执行不可逆操作。仅按关键词监控“delete / transfer / send”会漏掉改写，也会误报大量正常任务。

我们希望从 agent 的轨迹与激活 X 中恢复几个任务相关变量：授权清晰度 V₁、动作可逆性 V₂、外部影响范围 V₃、规避监督倾向 V₄。这些变量不必解释全部心智状态，只需对安全决策足够，并尽量不混入语言、网站主题等表面因素。

第一步：把安全概念写成“允许的等价类”

不要写“恢复 agent 的真实意图”这种无边界目标。写成可检验版本：

目标：恢复一个表示 V̂_auth 要求：对授权语义敏感；对语言、礼貌程度、网页主题不敏感 允许：单调缩放、同一安全子空间内的可逆变换 不允许：与操作不可逆性或表面关键词发生不可控混合

第二步：把学得结构当 advice，而不是真相

假设初步数据支持候选图：

授权含糊 V̂₁ ─→ 规避确认 V̂₄ ─→ 不可逆动作 Y 动作影响 V̂₃ ───────────────────→ Y

这张图可以指导下一次测试，但 representation error 会把边方向和节点语义一起污染。主动验证应挑“候选图分歧最大、执行风险可控”的干预，例如：

  • 在同一任务中只改变授权明确度，观察确认行为与最终动作；
  • 把真实提交替换为 sandbox dry-run，保持规划过程但隔离外部后果；
  • 对监控器高分与低分轨迹都做分层随机抽查，估计漏报。

“只要干预特征后行为改变，就证明特征是目标概念。”

特征干预可能同时改变多个 latent、破坏激活流形或引发分布外行为。还需要 specificity、负对照、跨 run 一致性与自然输入干预相互印证。

第三步：完成研究四卡

Input

多语言、多授权、可逆/不可逆的配对轨迹；激活；初始风险图；10% 人工审计预算。

Output

授权/可逆性安全子空间、候选因果图、带回退的轨迹抽查策略。

Cost

人工复核分钟数、受控 agent rollouts、真实环境干预风险、适应轮数。

Guarantee

建议准确时提高危险轨迹召回；建议失效时，漏报不劣于分层随机基线超过预设容忍度。

第四步：预注册“什么结果会让我认错”

  • 跨 SAE 随机种子，所谓授权特征无法匹配或方向翻转。
  • 保持授权不变、只换语言时，风险分数变化大于改变授权时。
  • 自然语言授权干预与 activation steering 给出相反行为效果。
  • 按监控器分配审计后，适应性红队的漏报率高于随机基线。
  • 去掉表征模块后，简单可观测特征达到相同性能与更强稳健性。

最后一条尤其重要：如果简单基线同样好，就不应因为“因果表示”听起来高级而保留复杂系统。
