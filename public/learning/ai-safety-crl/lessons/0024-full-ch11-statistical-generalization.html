1. 直接统计运输

Definition 11.2.1 — Direct statistical transportability (d-sTR)统计查询 Q=P(Y|X) 可从源域 i 直接运输到目标域 j，当所有与选择图兼容的域模型都满足 Pᵢ(Y|X)=Pⱼ(Y|X)；即无需目标域标签或额外因子重组，源条件分布本身就是目标条件分布。
Definition 11.2.2 — S-admissibility集合 X 对 Y 是 s-admissible，当在选择图中 Y ⟂ S | X。由 Markov 性得 P*(Y|X)=P(Y|X)。这是充分的图形准则；在相应模型类和 faithfulness 条件下也可用于排除。
Definition 11.2.3 — Structural covariate shift (SCS)所有特征 X 是 Y 的直接原因；Y 的结构函数及其外生分布跨域稳定；Y 不与 X 共享外生混杂。于是 P*(Y|X)=P(Y|X)，而 P(X) 可任意变化。三条件缺一均可能失败。

2. 从特征集合到表示

Definitions 11.2.4–11.2.9
Transportable feature set
给分数/预测函数，Z⊆X 若使目标统计（常为 E[Y|Z] 或 P(Y|Z)）直接可运输，则 Z 可运输。
Maximal transportable feature set
可运输且再加入任何剩余特征都会破坏可运输性的集合；按包含关系 maximal，不一定唯一，也不一定预测最优。
Representation and score
R=φ(X) 为特征的确定函数，分数 ψ(R) 用于预测/决策。φ 可降维，也可不可逆。
Transportable representation
若 P*(Y|R)=P(Y|R)，R 对 Y 可直接运输；图形上需在包含确定节点 R 的增强选择图中 Y⟂S|R。
Determined / constrained / free variables
给定 R 后必被唯一确定的是 determined；只受关系限制但不唯一的是 constrained；仍可独立变化的是 free。判断 R 是否阻塞路径不能只看输入集合，必须分析这些信息约束。
Augmented selection diagram
把确定表示节点 R=φ(X) 加入图，由其输入指向 R；再用确定性 d-separation 判断 S 与 Y。
随机一维投影也可能可逆
对有限集合 X∈{0,1}^d，随机连续 β 下 βᵀX 几乎必然不给两种 X 同值，因此一维 R 仍保存全部信息。维度小不等于信息少。

3. 数据驱动运输

Definitions 11.2.10–11.2.11
Data-driven transportable representation
不给真选择图，利用多个源域分布检验表示是否保持同一 P(Y|R) 或相应 score。结论依赖 causal mechanistic stability 与 r-faithfulness，不能由有限域经验等式无条件推广。
Source invariance property
对全部观测源域 i,j，Pᵢ(Y|R)=Pⱼ(Y|R)（或选定损失/分数相等）。它是可检验信号，不等价于对所有未见目标域必然稳定。

4. 风险不变与鲁棒方法的完整定义

Definitions 11.2.12–11.2.19
α-loss
对类别不平衡给正负类不同权重 α 与 1−α，使风险比较不被源域标签比例单独驱动。
UIRM
Uniform Invariant Risk Minimization：寻找表示与同一预测器，使它在各源域/各类权重 α 下同时风险最优；比只匹配平均风险更强。
Maximal transportable representations
在可运输表示偏序中信息最多且不能再无损扩展者；在假设成立时 UIRM 解与这类表示相关。
Linear SCMs with shared noise
多个域共享噪声结构与部分线性机制，域差异由 anchor/干预变量进入；使 anchor regression 有因果解释。
MM-REx
最小化源域风险仿射组合的最坏值，允许外推到训练域凸包之外；组合系数和为 1，可含负权。
V-REx
最小化平均风险加跨域风险方差惩罚；鼓励风险相等，但风险相等本身可由退化预测器实现。
Balanced-rate classification
按类别条件错误率而非标签比例加权的分类目标；在特定机制稳定条件下可跨标签偏移泛化。
Multi-calibrated score
分数 ψ 在指定子群/函数族上满足预测值与实际条件均值一致；与源不变结合可提供运输保证。

5. 部分测量运输

Definition 11.3.1 — Statistical transportability目标统计 P*(Y|X) 可由源域完整分布与目标域可测变量分布唯一计算。它比直接运输宽：可把源条件因子与目标边际/条件因子按图分解后组合。
Definition 11.4.1 — Discrepancy oracle布尔 oracle Δ(i,j;i′,j′) 回答两对变量/机制间的统计关系是否在源与目标间发生差异；域适应算法用有限询问定位结构方向或选择合适更新。理论样本复杂度取决于 oracle 准确度与候选结构。
Theorems 11.3.1–11.3.4分别处理目标域测 X、不测 Y；测 Y、不测 X；两者都不测但有可测 Z；以及把目标分布按 C-component 产品拆开运输。共同做法：在祖先图中分解目标因子，每个因子由源域或目标域可测分布承担。

6. 失败模式与原书 DANN 反例

DANN 失败
让域分类器猜不出 R，只保证 R⟂S 的某种经验近似；运输需要 Y⟂S|R。前者既非必要也非充分：R 可保留域信息但条件机制稳定，也可抹掉域信息同时丢失 Y 的因果预测量。
常数表示
R=0 在所有域完全不变，风险甚至可能相等，但通常没有预测信息。任何不变学习方法都要同时检查充分性/准确性与不变性。
AI safety：对不同模型版本/语言/攻击策略，报告 P(failure|R) 是否稳定，并明确 R 是表示、环境变化靶点、目标域能测什么；不要只给“域分类准确率 50%”。
