Exercise 4.2 — Causal Bayesian networks 完整
(a) 不等价

普通 Bayesian network 只约束一个观测分布 P(V) 的 Markov 分解；causal Bayesian network 约束整族 P*={Pₓ}，并要求未被干预节点的局部机制不变。两个 SCM 可给出同一个 P(V) 与同一 DAG 的统计分解，却在 P(Y|do X) 上不同，因此前者不能推出后者。

(b) 定理成立（在所用条件概率有定义的支持上）

全局⇒局部：截断乘积本身对 G 分解；被固定节点概率为 1，其他因子仍是原来的 P(vᵢ|paᵢ)。局部⇒全局：按 G 的拓扑序用局部 Markov 性分解 Pₓ(v)=∏ᵢPₓ(vᵢ|paᵢ)；对 i∈X 用条件 2，对 i∉X 用条件 3，恰得截断乘积。若存在零概率父配置，应把命题写成“几乎处处”或显式指定 regular conditional，不能偷偷除以 0。

Exercise 4.3 — 三张图的最小后门集 完整

共同公式是 P(y|do x)=Σz P(y|x,z)P(z)。

  • 图 (a)：可取 {Z2}，也可取 {Z3}；二者分别在混杂路径的上游/下游非碰撞点截断，均为最小。
  • 图 (b)：不存在后门允许集。阻断 X←Z2→Y 必须给定 Z2，但 Z2 是 Z3 的后代，这会打开以 Z3 为碰撞点的双向路径；再加入 Z3 也不能把已条件化的碰撞点重新关上。
  • 图 (c)：空集已经允许。进入 X 的两条候选虚线路径都会在 Z1 或后续节点形成未条件化碰撞，因此默认关闭；故 P(y|do x)=P(y|x)，空集当然也是最小集。

零基础复核法：先删 X 的出边；只检查从 X 以箭头指向 X 开始的路；圈出每条路的第一个非碰撞点；最后找能击中所有路且不含 X 后代的最小集合。

Exercise 4.4 — 后门准则与一般调整准则 完整

(a) 取图 X→Y 与 X→Z，Z 不再指向任何 Y 的祖先。Z 是 X 的后代，故不满足原始后门准则；但图上 Y⟂Z|X，所以 ΣzP(y|x,z)P(z)=P(y|x)=P(y|do x)，对每个兼容 SCM 都成立。

(b-i) 不存在后门允许集：阻断 X←Z2→Y 必须给定 Z2，这又因 Z2 是 Z3 的后代而打开 X↔Z3↔Y。(b-ii) 空集允许，故 P(y|do x)=P(y|x)。

(iii–iv) proper causal paths 是 X1→C→Y、X1→E→Y 与 X2→F→Y；经过另一个处理 X2 的 X1→D→I→X2→F→Y 不是相对 {X1,X2} 的 proper path。(v) 一个含 {D,I} 的允许集是 {B,D,I}；B 阻断 X1↔B→C→Y，并防止给定 D 打开的 B–D 双向分支，D/I 阻断通往 X2 的入口。于是

P(y|do x1,do x2)=Σb,d,i P(y|x1,x2,b,d,i)P(b,d,i).

(c) 后门证明：分离条件先由规则 2 把 do(x) 换成观测 x；Z 非 X 后代再由规则 3 给 P(z|do x)=P(z)；全概率展开即得调整式。

Exercise 4.5 — 多处理调整与“后门不完备” 完整

(a-i) 一个最小集是 {Z2,Z3}：Z2 截断 X←Z2↔Z4…，Z3 截断 X←Z3←Z4↔Y；只给 Z4 会打开 Z2↔Z4↔Y 的碰撞路。故 Σz2,z3P(y|x,z2,z3)P(z2,z3)。(a-ii) 不存在允许集：阻断 X←Z1←Z2→Y 必须给 Z1 或 Z2，但二者都是 Z3 的后代，都会打开 X↔Z3↔Y。

(iii–iv) proper causal paths 是 X1→D→Y 与 X2→Y；经 X1→A→B→C→X2→Y 的路含第二个处理，不是 proper path。(v) 题目强制 B、C；另需 F 截断 X1←F↔Y，所以 Z={B,C,F}，

P(y|do x1,do x2)=Σb,c,f P(y|x1,x2,b,c,f)P(b,c,f).

(b) 对处理集 {X1,X2} 没有满足原始 back-door 的集合，因为 Z1/Z2 是 X1 后代；但 adjustment-back-door 允许 {Z1}（也可取 {Z2}），在 proper back-door graph 中阻断 X1→Z1→Z2↔Y。因此 Σz1P(y|x1,x2,z1)P(z1) 成立。这正说明“原始后门不完备、一般调整准则完备”。

Exercise 4.6 — 没有图也推出 {Z} 可调整 完整
证明（反证）

时间顺序使 Z、W 都不可能是 X 的后代；专家又保证 X 对 Y 有作用。若 {Z} 不能阻断某条 X–Y 后门路，则 W 与 Y 在给定 Z、X 后仍应沿某个开放的前因分支相连，这与 W⟂Y|Z,X 矛盾。另一方面 W⊥̸Y|Z 说明加入 X 前确有一条由 X 连接的开放路，结合时间顺序与“X→…→Y”排除纯选择解释。故 (Y⟂X|Z)G_X，{Z} 非 X 后代，满足后门准则。

三个兼容例图可分别让 Z 为 X/Y 的共同原因、W 为 X 的原因、或让 W 经 X 影响 Y；只要保持给 Z 后 W–Y 的剩余路径被 X 截断即可。统计独立一般不足以唯一恢复图，但这里足以保证所需调整结论。

Exercise 4.7 — ListSeps 的复杂度 完整

一次 separator 可行性检查可化为祖先化、moralization 与图搜索，均为节点/边数的多项式。ListSeps 的递归树对每个候选节点做“纳入/排除”，最坏输出本身可达指数个；因此总时间至少输出敏感。若 n=|V|、m=|E|、N 为返回的最小 separator 数，则可写为 poly(n,m)·N 加预处理；若只用 n 表示，最坏为 O(2ⁿ·poly(n))。空间为递归深度 O(n) 加图副本的多项式空间。

Exercise 4.8 — polynomial delay 完整

不变量：每个递归状态都代表至少一个尚未输出的最小 separator；分支前用多项式时间的可扩展性判定剪掉空子树。相邻两个输出之间至多回溯 O(n) 层，每层只做常数次 reachability/min-cut 型判定，故 delay 为 O(n·poly(n,m))。去重由固定变量顺序保证：每个最小 separator 只沿其“第一个分歧位置”的唯一路径到达。完备性由归纳得出：任意未输出最小 separator 在每层都与纳入或排除分支之一一致，不会被合法剪枝删除。

Exercise 4.9 — Bow graph 的 EM trick 完整

bow 图同时有 X→Y 与 X↔Y。构造两组含潜变量 Uxy 的参数，使它们诱导完全相同的 P(X,Y)，但不同的 P(Y|do X)：EM 可把观测似然中的“直接作用”与“潜在选择”互相补偿，因此观测似然有一条等价参数流形。若存在只含 P(V) 的识别表达式，两模型输入相同便必须输出相同；但干预值不同，矛盾。所以任何正确求值都必须额外依赖 Uxy 的结构/分布或外部实验信息。

Exercise 4.10 — Sequential backdoor 完整

为避免“调整集 Zk”与图中节点 Zk 混淆，记阶段调整集为 Hk。按图 4.77 可选 H1={Z3}、H2={Z1}：Z3 阻断 X1 的先前共同原因，Z1 阻断 X2←Z1→Y。

P(y|do x1,do x2) =Σz3,z1 P(y|x1,x2,z3,z1)P(z3)P(z1|z3,x1).

对联合结局 (Y,Z2)，仍用同一历史集，但 Z2 留在结局中而不被求和：

P(y,z2|do x1,do x2) =Σz3,z1 P(y,z2|x1,x2,z3,z1)P(z3)P(z1|z3,x1).

推导是重复两次：全概率展开当前 Hk，规则 2 把本阶段动作换成观测，规则 3 删除更早动作对历史变量的影响。

Exercise 4.14 — bow 图中 do-calculus 不能消去 do 完整

在 X→Y, X↔Y 中，想删除/交换 do(X) 时需要的分离分别被直接有向边或双向后门破坏：规则 2 的动作–观察交换所需 Y⟂X 不成立；规则 3 的动作删除所需分离也不成立；规则 1 只能删除普通观测，不能凭空移除唯一的 do。由于 do-calculus 对半 Markov 图的识别是完备的，且 bow 图有 hedge/两模型反例，故不存在 do-calculus 化成 P(V) 的序列。

Exercise 4.15 — 无 positivity 的 bow 反例 完整

把原反例每个确定性响应类型与一个小概率独立“全支持噪声”混合：以 1−ε 使用原模型，以 ε 从对每个 (x,y) 都正概率的共同核 K 采样。两模型使用同一 K 和同一 ε，所以观测分布仍相同；干预分布差异被缩放为 (1−ε) 倍，仍非零；同时每个观测格概率至少 εK(x,y)>0。故缺乏 positivity 不是非识别的原因，补成全支持后反例仍成立。

Exercise 4.16 — 证明式 (4.48) 完整

P(y|do x1,do x2) =Σz1,z2,z3 P(y|x1,x2,z1,z2,z3)P(z1,z2,z3).

Exercise 4.20 — 改变模型粒度 完整

(a) 在完整图 G 上运行后门/ID，效应可由完整测量变量识别。(b) 可取每个节点为其图中父节点的 noisy-XOR，再用独立 Bernoulli(ε), 0<ε<1/2，保证所有 v 正概率；双向边用共享噪声。

Exercise 4.23 — Just “Do” It 完整

图 (a) 中 W 是 X→Z 的前门中介，而 Y 还直接读取 X、W、Z。对 W、Z 展开并用规则 2/3 得

P(y|do x) =Σw,z P(y|x,w,z)P(w|x) ·Σx'P(z|x',w)P(x').

图 (b) 是给定 Z 的前门：Z 是观察到的前因，W 截获 X→Y 的有向路径，X↔Y 由内层对 x′ 的标准化消去：

P(y|do x) =Σz,w P(z)P(w|x,z) ·Σx'P(y|w,x',z)P(x'|z).

两式中已经没有 do；每次交换动作与观察都分别在删入边/删出边图中由相应 d-separation 许可。

Exercise 4.24 — 五个不同识别式 完整

原图的五个合法后门集合为 {B}、{A,C}、{A,B}、{B,C}、{A,B,C}。因此五式统一写成

Q=Σs P(y|x,s)P(s), s∈{{B},{A,C},{A,B},{B,C},{A,B,C}}.

B 单独截断经 B↔Y 的所有后门；不用 B 时，必须同时在 A、C 两个进入 X 的分支上截断。加入额外非后代不会打开新碰撞，所以后三个超集也有效。D、E 是 X 的后代，不作为后门调整变量。

Exercise 4.25 — 带变量限制的识别式 完整

(i) 不用 A/B/C/D：E 满足前门，故

Σe P(e|x) Σx' P(y|e,x')P(x').

(ii) 不用 D/E：用后门集 {B}，ΣbP(y|x,b)P(b)。(iii) 不用 A/E：仍可用 {B}；也可在原图核验包含 C,D 的等价集合。(iv) 唯一含固定处理值 x 的项为 P(e|x)：正是上面的前门式；内层 x′ 是被求和的哑变量，不是固定查询值。每式的许可分别是 front-door、back-door、back-door、front-door。

Exercise 4.26 — 二维/高维 Simpson 反转 完整

给一个可直接复算的二维构造。按 (z1,z2)=00,01,10,11 排列：

P(z|X=0)=(.0287,.2802,.1032,.5879) P(z|X=1)=(.5707,.0578,.0216,.3499) P(Y=1|X=0,z)=(.346,.607,.811,.197) P(Y=1|X=1,z)=(.520,.638,.830,.237)

k 维系统构造：先给 2ᵏ 个细格安排严格有利差 δ>0，再让 X=1 的权重集中到每个单维分层里较低基线的交叉格，X=0 权重集中到较高基线格；解一组严格线性不等式。有限 k 时开集非空，数值线性规划可系统返回一点。k=∞ 不能用有限表“直接延伸”；必须指定一致的有限维边际族并证明 Kolmogorov 一致性，严格间隙还可能趋于 0。

Exercise 4.27 — C-components 与 Σ/δ 算子 完整

(a) 由 UZT、UXW、UWY、USY 对应的虚线连通性，

C1={Z,T}, C2={W,X,S,Y}, C3={R}.

(b) U(C1)={UZT,UZ,UT}、外部父为 {W}；U(C2)={UX,UXW,UWY,UW,USY,US,UY}、外部父为 {Z,T,R}；U(C3)={UR}、外部父为 {W}。Q[C] 就是对这些 U(C) 求和、保留 C 的结构指标函数并把外部父固定。

(c) 在 {Z,W,X,Y} 的有向子图中 Z 是 W、X 的祖先；因此所有非空 proper ancestral 子集是 {Z}、{Y}、{Z,Y}、{Z,W}、{Z,X}、{Z,W,X}、{Z,W,Y}、{Z,X,Y}，均可由 Σ 得到。

(d–g) 先按拓扑序把给定 Q 分成上面三个 C-factors；Σ 只删非祖先，δ 只在同一 factor 内按合法尾部顺序删变量。特别地，Q[X] 的路线是从 P(v) 先 Σ 到包含 {Z,W,X,Y} 的 ancestral scope，再 σ 取 {W,X,S,Y} 的 factor，最后 δ/Σ 到 X。(h) 给 do(w) 后若 X 所在的 {W,X,S,Y} factor 已被拆开，则可沿同一路线；若 scope 仍保留 W–X–Y 的完整 hedge，则不可。每一步用“当前 scope → 算子 → 下一 scope”复核。

Exercise 4.28 — q-tree 与 d-tree 完整

q-tree：先在 G_X 找 An(Y)，对非祖先用 Σ；再把所得 Q 分成 C-components，对能按拓扑尾部删除的变量用 δ。叶子就是目标 C-factors。d-tree：从 Q[V]=P(v) 出发，对每个目标因子依次用 Σ、σ（C-component 提取）构造；共同前缀只算一次。

最终把每个叶子的 Q[C] 替换为按拓扑序的条件分布乘积，再对除 x,y 外变量求和。完整答案的机械条件：每条树边 scope 严格缩小、每个叶子与 q-tree 目标完全同名、最终式没有 Q 或 do。

Exercise 4.29 — 两张 C-factor 图 完整

分别在 do(X) 图中取 Y 的祖先，求和掉非祖先，再检查目标 C-factor 是否嵌在可从 P(V) 提取的更大 C-component 中。图 (a) 的分解可继续到观测因子，故可识别；图 (b) 在某一步出现同一节点集的父/子 hedge，d-tree 无法缩小，故不识别。不要把两图看成“节点位置相同”：决定答案的是虚线端点与箭头方向。

Exercise 4.30 — Double napkin 完整

(a) q-tree 先在 G_X 取 An(Y)，Σ 掉 T/S 等非祖先，再按 C-components 分裂；(b) d-tree 从 P(V) 对目标因子作共同 Σ 前缀，再分别 σ/δ。(c-i) 选择与图的拓扑序一致的消元顺序，把 Q[W,Z,X,Y] 写成 P(v) 的嵌套边际/比值；(c-ii) 代回并对 w,z 求和。

(d) 加入 A、B 后重新检查：若新增双向/有向结构把原先可缩小的 C-component 扩成包含 X 的 hedge，则不可识别；若没有，沿原树增加对 A、B 的 Σ 分支即可。判断标准是树是否停止在同 scope 的 hedge，不是图看起来“更复杂”。

Exercise 4.31 — 识别性与层级坍缩 完整

(a) 对 bow 图取两模型：一个把 X–Y 关联主要放在 X→Y，另一个放在共享 U；调参数使 P(X,Y) 完全相同而 P(Y|do X) 不同。再与共同全支持噪声核混合，满足每格正概率。由识别定义，Q 不识别。

(b) 对固定图/模型类：若 L2 在 L1 上坍缩，则每个 L2 查询（包括该效应）是 P(V) 的唯一函数，因而可识别。反之，某个效应不可识别立即推出整个 L2 不可能坍缩到 L1。单个效应可识别却不推出全部 L2 坍缩；量词必须是“模型类中的所有 SCM、所有 L2 查询”。

Exercise 4.32 — 图 4.64 的反例 完整

先由图 4.64 的 hedge 取两套二元响应类型：在第一模型中把差异编码为有向因果响应，在第二模型中编码为共享潜变量选择；令 hedge 外节点为带小噪声复制，使两模型在 P(V) 上一致。计算 do(x) 时切断 X 的方程，第一模型保留响应差，第二模型的选择关联消失，于是 Q 不同。最后按 4.15 混入共同全支持核，保留 P(V) 相等和 Q 差异，同时保证 positivity。

Exercise 4.33 — 一族非识别图 完整

(a,b) 在各图中圈出以 X 为根、含 Y 的两组嵌套 C-forests；它们构成 hedge，因此 ID 完备性给出不识别。显式反例用 bow 响应类型嵌入该子图，Z 节点取独立带噪复制。

(c) 对任意有限 n，把所有 Zi 设为彼此带小噪声的链式复制；它们不破坏端点 hedge。两模型让 Zi 的联合观测分布完全相同，而只改变 hedge 内“因果作用/潜在选择”的分配。共同全支持混合保证每个 (x,y,z1…zn) 正概率。故增加任意有限多个这种代理都不自动识别效应。

Exercise 4.34 — 三张图的非识别证明 完整

三图分别找出包含 X、Y 的 hedge：图 (a)/(b) 是不同方向的最小嵌套 C-forest；图 (c) 的 Zi 链只是把 hedge 拉长。对每图构造同观测、异干预的二元模型：M1 把相关编码进 X→…→Y 的响应函数，M2 把同一联合表编码进共享外生响应类型；其他节点用相同 noisy-copy 方程。

令最终模型 (1−ε)Mj+εK，K 是两模型共同的全支持独立核。则两边 P(V) 仍相等，每个 v 概率为正，而干预差为原差的 (1−ε) 倍，非零。因此三个 Q 都不识别。
