多个环境，是多份带标签的线索

单个分布里纠缠在一起的结构，可能在多个域的机制变化中显露出来。关键不是“数据更多”，而是知道或推断哪里发生了变化。

学完你能：区分 domain 与 intervention，用共享/变化机制解释多域为何帮助定向，并避免把域差异误当随机实验。

域到底是什么

域（domain）是一种数据生成环境：不同医院、物种、语言、模型版本、训练阶段都可以是域。域之间至少一个机制或背景分布不同。

对比我们通常知道什么因果强度
更多同域样本同一机制下重复观察减少估计噪声，不增加变化线索
多个观测域环境标签；变化靶点可能未知提供异质性，但可能带混杂
理想干预域谁被外部改变、怎样改变可切断旧父边，定向力更强
“来自不同国家/模型”不等于“做了干预”。域差异可能同时改变许多机制，也可能由选择偏差造成。只有明确操作和靶点时，才可直接使用干预语义。

变化本身可以定向

假设候选是 X → Y 或 X ← Y。若跨域只发现 X 的生成机制变化，而 P(Y|X) 保持稳定，这更符合 X→Y：上游 X 变了，稳定的 Y 机制继续读取 X。若是 Y→X，则改变 X 的机制不该自然保留同一 P(Y|X) 模式。严格结论仍依赖“独立机制”等假设。

温度计跨工厂
X=真实温度，Y=故障。工厂 A 与 B 的生产任务让温度分布不同，但“给定温度的故障机制”稳定。变化集中在 X，支持温度是上游。若更换了冷却系统，使同一温度下故障风险也变化，那么 Y 的机制也变，不能继续套用同一不变量。

原书人类/倭黑猩猩式例子

不同物种可被看作多个自然域。若某些脑区测量关系跨物种稳定，而另一些机制发生系统变化，这些变化可帮助缩小候选结构。不过物种差异并非单靶点随机干预；结论需要生物机制、测量可比性与选择过程的额外知识。

选择节点把域差异接回图

给每个可能变化的机制加选择节点：S_X → X 表示 X 的条件机制随域变。多个域的联合独立性和不变性可排除部分候选结构。第 17 章把第 10–11 章“已知图上的运输”推进到“利用域变化帮助学图”。

LLM 多模型版本
在基础模型、指令微调模型、安全微调模型上测量概念 A=权威暗示、B=内部服从表征、C=有害执行。如果只知道版本标签，不应直接把变化称为 do(A)。但若训练日志说明安全微调主要改变 B 的生成机制，而 A 的输入机制固定，跨版本变化就能为 A—B—C 的方向提供额外证据。

零基础可执行流程

  1. 列域：写出每个数据集/环境是怎样得到的，而不只写名称。
  2. 列可能变化靶点：输入人群、测量、标签规则、训练目标、选择过程各自是否变。
  3. 列候选不变量：哪些条件机制有理由跨域保持，并设计检验。
  4. 保留等价类：输出被多域证据排除后的候选图，不强行给每条边定向。
  5. 选择新域/干预：比较哪种安全可执行变化最能区分剩余候选。
