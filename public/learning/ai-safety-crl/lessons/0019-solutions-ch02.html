Exercise 2.7 — 两张图生成给定 P*
答案

(a) 表中 Z、X 独立公平。设 Uz,Ux 独立公平；Z=Uz,X=Ux；用独立均匀 Uy，令 Y=1[Uy<qzx]，其中 q00=.1，q01=q10=q11=.9。兼容 Z→Y←X。

(b) 令外生 H 直接编码三元组 (X,Y0,Y1)：X 边际公平，P(Yz=1|X=x) 取表中对应条件；令 Z 独立公平，Y=Y_Z。H 同时进入 X、Y，形成 X↔Y，且 Z→Y。选择任一满足给定边际的 Y0/Y1 coupling 即可。

Exercise 2.8 — 任意 P* 与双向图
答案

(a) 完全双向三角可表示任意 P*：令单一外生 U 取值 (z,x,y)，分布就是 P*，三个方程分别投影 U。

(b) 纯双向链 Z↔X↔Y 蕴含 Z⟂Y；因此“任意 P*”一般无法构造。仅当 P* 满足该独立时，可令独立潜因 UZX、UXY 生成相邻对。此题的关键正是检查图的可检验限制。

Exercise 2.9 — 从 P 与 G 构造 SCM
算法

按 G 拓扑序。为每个 Vᵢ 引入独立 Uᵢ∼Unif(0,1)；对每个父值 pa，用条件分布 P(Vᵢ|pa) 的累积区间定义逆 CDF fᵢ(pa,uᵢ)。Markov 条件给 P(v)=∏P(vᵢ|paᵢ)，故构造诱导 P 且图不增加额外父依赖；若要求每条边功能上有效，可在零概率/等价区间作微小编码并保持分布。

Exercise 2.10 — XOR 干预
答案

每个变量都有独立公平 Ui 进入 XOR，因此其输出在给定其他父值时仍公平。(a) P(Y=1)=1/2；(b) P(YX=1=1)=P(YX=0=1)=1/2；(c) P(YZ=1=1)=P(YZ=0=1)=1/2（原稿一处把第二项排成 P(YZ=1=0)，也为 1/2）。(d) 所有候选干预对 Y 无平均收益，也无反作用。

2.11–2.20：构造、层级与 graphoid

Exercise 2.11 — 填 SCM 满足五项约束
解题条件

先画必需结构：Z、W 无相互因果；W 与 X 的观测关系必须经一个在 do(Z) 后被阻塞而在观测 Z 时开放的路径产生；W 与 Y 相关但无效应；X→Y 且正效应。可取图 W←U→Z→X→Y 并增加 Z←U′→X 调整概率，使 P(X=1)=3/4；Y 取 X∧U2 或其单调变体。把共享外生变量填入相应空格，最后逐项用枚举 2^|U| 验证。构造不唯一；关键验算是把 do(w)、do(z) 写成替换方程，而非条件化。

Exercise 2.12 — Simpson 反转 SCM
一种结构答案

必须有 Z→X→Y，且 Z 与 Y 有后门联系，使观测关联方向与 X 的干预作用相反；同时 do(X) 后 Z 对 Y 无额外信息。选 Z=U1，让 X 高概率等于 ¬Z，让 Y=X∨Z（再加独立噪声调为严格不等式）。则 X→Y 为正干预效应，但 X=0 组富集 Z=1，可令观测 P(Y|X=0)>P(Y|X=1)。用给定 P(U1)=3/4 及两个新增 Bernoulli 噪声调阈值即可；图是 Z→X、Z→Y、X→Y。

Exercise 2.13 — 指定边际与条件依赖
答案路线

令新增 Uzw 同时进入 Z、W，制造 Z↔W；保留 Z→W→X→Y，并让共享 Uzy 进入 Z 与 Y，确保 P(y|do(x),z) 仍随 z。用 P(Uz=1)=2/5 满足 Z 边际；将 X 的新增噪声概率选成解方程 P(W⊕Ux=1)=9/10 的值。最后列出图 Z→W→X→Y、Z↔W、Z↔Y。

Exercise 2.14 — 干预 Z 改变 Y 但给定 X 无额外作用
答案路线

需要 Z→W→Y 形成因果效应，同时 X 与 Y 的条件依赖通过 Z 选择/混杂产生；要求 Y⟂X|do(Z)。可令 Z=X⊕Uz，W=Uw⊕Z，Y=W⊕Uy，并用共享外生源在 X、Y 间产生观察依赖；干预 Z 切断 X→Z 后消除。用新增 Bernoulli 噪声调 P(Y=1)=9/10。图形条件比具体 XOR 填法更重要，所有五式可由枚举核对。

Exercise 2.15 — 嵌套反事实可定义
证明

一级嵌套：Y_{X_{z}=x}(u)=y 等价于对 x 枚举并合取 X_z(u)=x ∧ Y_x(u)=y，再对 x 析取。任意嵌套按深度归纳：选最内层反事实 T，枚举其有限取值 t，用 L3 事件 T=t 与把外层 T 替换为 t 的表达式合取；后者深度减少。有限析取仍属于 L3。

Exercise 2.16 — L1 与 L2
答案概要

(a-i) Z→Y←X：独立抽 Z,X，再按 P*(Y|Z,X) 逆 CDF；(ii) 令四值 Z 直接编码 (X,Y)，X、Y 读 Z；(iii) X↔Y：共享 U=(X,Y)∼P*。

(b-i) 在 (i) 中选某 u 使 fY 真正读取 X，便有 Yx≠Y；(ii) 纯 X↔Y 无 X→Y，干预 X 不改 Y 方程，故逐 u 有 Yx=Y；(iii) 构造中的 P(Y)=p01+p11，而 P(Yx0) 由为 x0 指定的响应类型质量决定，可与前者不同；(iv) 无有向效应模型恒为 p01+p11。

(c–e) 对任意观测分布均可构造有作用与无作用的低层等价模型；把 U 直接编码整向量可得到完全双向图。因此一般 L2 不坍缩到 L1。

Exercise 2.17 — 同观测、同 CI、不同干预
答案

(a) 把链 X→Y→Z 改成 Markov 等价链 X←Y→Z，并用 Bayes 法令 P2(y)=ΣxP1(x)P1(y|x)、P2(x|y)=P1(x)P1(y|x)/P2(y)、保留 P1(z|y)，即 P2=P1；二图 CI 都是 X⟂Z|Y，但干预不同。

(b-i) 这对模型只证明某个查询不识别，不单独证明给定 M1 的“所有 L2 查询”关系；(ii) 若 b≠c，可用 P(Y|do(X=x))：M1 随 x，M2 等于 P(Y)。

(c-i) False：训练出的 M 可能是低层等价的错误机制；(ii) True，若对固定 G、P 的每个 L2 查询在所有兼容 M 上唯一，则按定义 L2 相对该模型类坍缩。

Exercise 2.18 — Collapsibility 特例
答案

已完全知道 M* 时，所有层都可由方程直接计算，但这不是从低层分布“无假设识别”。该模型 Y:=X，故 Yx=x，L2 由结构已知；L3 也由同一 U 和确定函数得到。若 M* 未知，分析者至少要知道方向/函数（Y 由 X 复制）、外生耦合与 P(U)；仅 P(X,Y) 不能排除共同原因模型。

Exercise 2.19 — CHT
证明路线

(a) 用 X→Y 与 X←Y 两个 Markov 等价模型匹配同一 P(X,Y)，但 P(Y|do X) 不同。(b) 二元 X,Y 与一个共享外生变量已足够。(c) 若所有响应确定且 L2 分布固定联合响应类型（例如 Y 不受 X），L3 可坍缩。(d) 一般 L2 只给各潜在结果边际，不给 (Yx,Yx′) coupling；连续可调 coupling 形成正维集合，故除退化测度零模型外不坍缩。

Exercise 2.20 — Graphoid axioms
证明摘要

Symmetry 由乘法交换；Decomposition 对 W 求和；Weak union 用 P(x,y,w|z)=P(x|z)P(y,w|z) 除以 P(w|z)；Contraction 把 P(x|y,w,z)=P(x|z) 与 P(x|y,z)=P(x|z) 代入链式分解；Intersection 在 positivity 下分别得 P(x|y,w,z)=P(x|w,z)=P(x|y,z)，连通支持迫使等于 P(x|z)。路径版本逐条检查阻塞对称与集合增删。

无 positivity 时 intersection 失败：令 Y=W=X 为同一非退化比特。给定 W 时 X⟂Y，给定 Y 时 X⟂W，但 X 不与 (Y,W) 无条件独立。

2.21–2.34：图形推理

Exercise 2.21 — L1 modularity
证明

Markovian 意味 Ui 与其他节点外生源独立。由 Vi=f(Pai,Ui)，给定 Pai 后 Vi 仅含 Ui 随机性；非后代去掉父集的变量是其他外生源和早期机制的函数，故与 Ui 独立。对 Ui 边际化即得 Vi⟂NDi\Pai|Pai。

Exercise 2.22 — 链、叉、碰撞 SCM
构造

链：X=Ux，Z=X⊕Uz，Y=Z⊕Uy；叉：Z=Uz，X=Z⊕Ux，Y=Z⊕Uy；碰撞：X=Ux，Y=Uy，Z=X∨Y。选择非公平小噪声避免抵消。前两者 X,Y 边际相关、给 Z 后独立；碰撞边际独立、给 Z 后依赖。散点/列联表应显示此反转。

Exercise 2.23 — Common cause
答案

(1) 令 Z 公平，X=Z⊕Ux、Y=Z⊕Uy，噪声错误率均 .1，则 P(X=Y)=.82>.5，故相关。(2) 图 X←Z→Y 中，给定 Z 后独立由分解强制，对任何兼容 P(U)（满足图的 Markov 设定）都不能令其失败；题面末项 P(y|y) 是排版错误，应为 P(y|z)。

Exercise 2.24 — Reichenbach
答案

(1) 取 P(00)=P(11)=.4、P(01)=P(10)=.1。模型 A：X 公平、Y=X 以 .8 概率；模型 B：H 公平，X、Y 各以 .1 概率翻转 H。两者可调成同一表，一个直接因果，一个共同原因。

(2) 若允许选择偏差，取独立 X,Y 后只保留 X=Y 的样本，观察分布相关，却无 X→Y、Y→X 或生成阶段共同原因；相关来自共同选择结果。故原则需因果充分性/无选择等条件。

Exercise 2.25 — Extended collider
答案

按 Eq.2.87 枚举 U 并用 P(a|W=0)=P(a,W=0)/P(W=0) 得三项；判定不必依赖数值：W 是 X、Y 的共同后果或其后代，条件化 W 打开 X→…←Y 路径，所以一般 P(X,Y|W)≠P(X|W)P(Y|W)。若参数刚好抵消则是非 faithful 例外。

Exercise 2.26 — d-connected nodes
答案

在 G 给 B 时，从 A 经 C←F←H→I→E 的开放路可达 C,F,H,I,E；经 A←B←D←G 的路被 B 阻塞，故 D,G 不可达（端点 B 通常不列入查询集合）。在 G′ 给 J 时，从 A→G→J 路在 J 终止；按 Bayes-ball 沿 A→D、D←B、D→E←C、E→I 及 H 相关路径逐一检查，条件化 J 不会自动打开 E 的碰撞，结果以原图的开放非碰撞分支为准。

Exercise 2.27 — Alarm 网络
答案

(a) 给 J=1 会打开 B/E→A←S 的碰撞结构；仍由图可读的独立包括根节点先验独立在未被 J 后代选择破坏的对应分支，以及 M 与 J 在给定 A,C,S 后独立。完整列举用 moralized ancestral graph。

(c) 精确枚举得到：P(M=1)=0.064037245；P(J=1|C=0)=0.008400292；P(E=1|M=1,B=0)=0.04911539；P(M=1|B=1,J=0)=0.65247507。

Exercise 2.28 — 图 G 的分离与边际图
答案方法

(a) X 与 W 的有向链经 Z，最小分离集含 Z；同时检查 X↔Z 等路径，若 Z 为非碰撞仍被堵。(b) X–S 的路径经 Z,W 或 T，按原图最小集由 {Z,T} / {W,T} 等候选逐条检验。(c) 对 Z–Y 列所有路径，分别用 W、S、T 的非碰撞点堵住，排除会打开碰撞的集合。(d) 边际化 Z,T 后，对 {X,S,W,Y} 作 latent projection：每条经隐藏非碰撞点的有向路径加有向边，经隐藏共同原因路径加双向边；再 maximal 化。

Exercise 2.29 — 每个 V 与 X 的最小分离
答案方法

按原图：对每个 V 枚举 X–V 路径；直接相邻节点不存在不含端点的分离集；非相邻节点优先取 X 与 V 的祖先集减端点，再删冗余。边际图 {X,S,W,Y} 用 latent projection：X→Y、Y→W、W→S 等隐藏路径保留/补边，Z、R 引起的共同原因转为双向边，再删除任何可由其他边蕴含的冗余。

Exercise 2.30 — 大图 d-separation
答案

(a) 每问可取祖先集法：在 X、Y 祖先诱导图中 moralize，删端点后找分割集；例如 A–F 可由 {B,C} 堵，A–I 可由 {B}（依原图各路复核），D–{F,H,G} 与 B–E 同理取所有非碰撞入口。(b) 每个 X 的最小 Markov blanket：父、子、子之其他父；这使 X 与其余节点条件独立。(c) 若任意 Z 可分离，则祖先候选 Z0=An(X∪Y)\(X∪Y) 也可：开放路径若含非祖先必含未激活碰撞；反向显然。带允许集 R/I 的证明同理把祖先截到 R。

Exercise 2.31 — Lack of separation
证明

图中 X、Y 间存在一条无内部可条件化节点的直接有向或双向边，因此任何 Z⊆V\{X,Y} 都不能阻塞；故不可分离。构造线性高斯 SCM，给该直接边非零系数、其他边取代数独立非零系数，则所列各条件集下偏相关为非零；除有限个多项式零集外都成立。

Exercise 2.32 — 稀疏与独立
答案

(1) Markovian DAG 中无直接边至少给局部 Markov 独立：节点给定父后与非后代独立；缺边可通过 d-separation 找到相应集合。(2) 非 Markov 时，X、Y 方程互不读取对方，但相关 Ux,Uy 使 X↔Y，任何集合都不能分离。(3) 一般准则就是 ADMG 的 d/m-separation：缺边只有在存在某集合阻塞全部有向与双向路径时才转成 CI。

Exercise 2.33 — 含非祖先的路径必有碰撞
证明

反设路径 p 无碰撞。沿 p 从某内部非祖先节点向两端观察箭头；无碰撞意味着箭头方向不能在该点或后续形成“→·←”相撞，故至少一侧形成连续有向路径通往 X 或 Y，使该节点成为 X 或 Y 的祖先，矛盾。

Exercise 2.34 — d-sep 算法可靠性
证明

Bayes-ball 的每条传播规则与三元组开放规则一一对应：给定节点阻止链/叉的球，未给定碰撞点阻止相撞方向，给定碰撞点或其后代允许反向传播。归纳路径长度：算法到达 Y 当且仅当存在一条给定 Z 的开放 trail；因此报告 separated 时确无开放路径，声称 sound。
