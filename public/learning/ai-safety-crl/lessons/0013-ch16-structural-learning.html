为什么真图可能不唯一

下面三张图都没有碰撞点，并预言相同的条件独立：给定 B 后 A 与 C 独立。

A → B → C A ← B → C A ← B ← C 共同预言：A ⟂ C | B

只靠满足这些独立关系的观测数据，无法确定是链向左、链向右还是 B 为共同原因。它们属于同一个 Markov 等价类。

但 A → B ← C 不同：它预言 A 与 C 原本独立，给定 B 后依赖。因此骨架 + 未遮蔽碰撞点决定等价类。

CPDAG 是不确定性的地图

CPDAG 用有向边表示整个等价类都同意的方向，用无向边表示仍可两向。算法返回 A — B → C 不是失败；它精确告诉你：B→C 可由假设与数据确定，A—B 仍需要额外信息。

PC 算法的零基础流程

PC 是约束型结构学习的经典代表。假设因果充分性（没有遗漏共同原因）、无环、Markov 与 faithfulness，并有可靠独立性检验。

  1. 从全连接开始：A、B、C 每两点之间先都连边，表示暂不排除直接关系。
  2. 用独立性删边：若发现 A 与 C 在给定 B 后独立，就删 A—C，并记录分离集合 Sep(A,C)={B}。
  3. 找碰撞点：若 A 与 C 不相邻，却共享邻居 B，且 B 不在分离集合中，则定向 A→B←C。
  4. 传播方向：继续用避免新碰撞与避免有向环的规则，定向能确定的边。
三变量安全例子
A=用户危险意图，B=模型内部风险评分，C=拒答。若 A 与 C 原本相关，但给定 B 后独立，骨架可能是 A—B—C，说明评分屏蔽了路径。仅此仍不能确认 A→B→C；需要时间顺序、机制知识或干预。但若 A 与 C 原本独立，条件化 B 后相关，则 B 更像碰撞点，而不是中介。

faithfulness 为什么是实质假设

图中存在路径，参数却可能刚好相互抵消，让数据呈现独立。faithfulness 假设排除这种精确抵消，使“看到独立就删边”可用。真实系统近似抵消或样本不足时，独立检验会不稳定，因此边的置信度和敏感性分析很重要。

一个干预怎样打破等价

对 A 做随机干预：若 B 的分布随之改变，支持 A→B；若 A 原本只是 B 的结果，切断 A 的父边不会向上游改变 B。选哪个节点干预，决定能排除多少候选图。

主动安全审计
候选图对“提示权威感 A、内部顺从特征 B、有害服从 C”的方向有分歧。预算只允许一次实验。可以比较干预 A、B、C 后各候选图预测的分布：优先选择让候选图预测差异最大的、且安全可执行的干预，而不是随机挑节点。
Davin Choo 的接口在这里出现：主动因果发现问“下一次干预哪里最有信息”；imperfect advice 再加一层——建议器可能出错，你要在有限轮数/预算下稳健地利用建议，而不能把顾问当真图。
方向发现不等于因果作用大小估计。结构学习先问边与方向；知道 X→Y 之后，效应数值仍需识别条件、实验设计和估计。
