1. 目标查询与识别

Definition 4.1.1 — Interventional distribution / causal effect对不相交 X、Y，P(y|do(x)) 是在子模型 Mₓ 中 Y 的分布。它可指联合、边际或条件效应；“效应”不是单一数字，必须写出处理、结果、目标人群与条件。
Definition 4.2.1 — Effect identifiability给定图 G 与可用分布集合，若任意两个与 G 和数据兼容的 SCM 都对目标 Q 给出同一值，则 Q 可识别。识别是模型类上的唯一性；估计是有限样本下逼近已识别函数。
Truncated factorization在 Markovian DAG 中，P(v|do(x))=∏_{Vᵢ∉X}P(vᵢ|paᵢ)（与 x 一致时；否则 0）。它删除被干预节点的条件因子，保留其余机制。

2. 调整准则的完整条件

Definition 4.2.2 — Back-door criterion集合 Z 相对 (X,Y) 满足后门准则，当：(1) Z 不包含 X 的后代；(2) 在删除 X 发出边的图 G_X̲ 中，Z d-separate X 与 Y。则 P(y|do(x))=Σ_zP(y|x,z)P(z)。
Definitions 4.2.3–4.2.4 — Proper causal path 与 A-BDCproper causal path 从 X 中一个节点出发后不再经过其他 X 节点。调整后门准则要求 Z 不含 proper causal path 上非 X 节点的后代，并在删除 proper causal path 第一条边的图中阻塞所有非因果路径。它对多处理和一般调整是完备的。
Definition 4.2.5 — Front-door criterionM 相对 (X,Y) 满足：(1) M 截断 X 到 Y 的全部有向路径；(2) X 到 M 没有未阻塞后门；(3) 给定 X 后，M 到 Y 的全部后门被阻塞。公式：Σ_m P(m|x) Σ_x′ P(y|m,x′)P(x′)。
Definition 4.2.6 — Generalized front-door允许处理、结果、中介为集合，并用图上的可识别子效应替代简单三条件；核心仍是把总作用分解成可识别的 X→M 与 M→Y 部分。
为什么后门变量不能“全塞”
严重度是处理前共同原因，应调整；治疗后的生物指标是中介，若目标是总效应则不应调整；入院资格若是处理和结果共同后果，是碰撞点，调整反而开偏差路径。

3. do-calculus 三条规则

记 G_X̄ 删除指向 X 的边，G_Z̲ 删除 Z 发出的边。每条规则只有在相应改图中满足 d-separation 才能用。

Rule 1 — 插入/删除观察若 (Y ⟂ Z | X,W)_{G_X̄}，则 P(y|do(x),z,w)=P(y|do(x),w)。
Rule 2 — 行动/观察交换若 (Y ⟂ Z | X,W)_{G_X̄,Z̲}，则 P(y|do(x),do(z),w)=P(y|do(x),z,w)。
Rule 3 — 插入/删除行动令 Z(W) 为 Z 中不是 W 在 G_X̄ 中祖先的节点。若 (Y ⟂ Z | X,W)_{G_X̄,Z(W)̄}，则 P(y|do(x),do(z),w)=P(y|do(x),w)。
Soundness & completeness三条规则对半 Markovian 图是可靠的；若一个观测识别任务可识别，就存在 do-calculus 推导把 do 表达式化为 P(v) 的函数。算法 ID 把这种存在性变成程序。

4. 算法化识别的定义

Definitions 4.4.1–4.4.5
Task signature
用 ⟨M,I,Q⟩ 描述模型类、可用信息和目标查询；同一个 Q 在不同 I 下识别性不同。
C-factor Q[C]
Q[C](v)=P(c|do(v\c))：把 C 外所有观测变量固定后 C 的联合机制因子。
C-operator
在已有因子上进行边际化 Σ、利用独立性 δ、跨制度不变性 σ、去条件 Γ 等合法映射。
C-components
双向边连通分量；识别算法按这些潜在混杂块分解。
Causal factor tree / c-tree
节点是因果因子，边标记合法 operator；q-tree 分解查询，d-tree 从可用分布导出目标因子，叶匹配即给识别式。
Definitions 4.7.1–4.7.3（习题区补充）
Global compatibility
全部干预分布都满足截断因子分解。
Local causal Bayesian network compatibility
每个干预分布在 G 上 Markov；被干预节点退化到指定值；未被干预节点的局部机制在父值相容时不变。
Minimal adjustment set
满足调整准则且没有真子集仍满足的集合；“最小”按包含关系，不一定是基数最少或成本最低。

5. 非识别不是暂时不会算

正式证明有两条路线：(1) 构造两个兼容 SCM，它们产生相同可用分布但目标 Q 不同；(2) 在 ID 算法中找到 hedge/不可分解 C-component。Bow graph X→Y, X↔Y 是最小例：直接作用与未测混杂无法由 P(X,Y) 分开。

不能用回归或更大网络绕过。估计器可选择一个答案，但另一个兼容世界同样拟合全部观测。除非加入实验、代理变量、函数限制或新假设，否则没有数据内的唯一性。

6. 软干预

Definition 4.6.1 — Interventional model硬干预把函数替换为常数；软干预把目标节点原条件机制替换为另一机制/分布，通常保留父结构或明确改变部分参数。第 4.6 节通过扩展变量和 σ-calculus 把软干预查询还原为可处理的硬干预问题。
LLM 安全微调是软干预
它不是把“拒答倾向”固定成 1，而是改变模型从提示到内部状态/输出的条件机制。若把它误写成 do(R=1)，会删掉训练实际保留的输入依赖。
