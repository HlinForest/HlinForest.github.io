1. 有潜变量时的图对象

Definitions 16.1.1–16.1.8
Mixed graph
允许有向边和双向边的无环祖先图；不能有有向环，也不能让箭头指向自己的祖先。
Markov property
图中 m/d-separation 蕴含分布中的相应条件独立。
Markov equivalence
两图蕴含完全相同的条件独立集合。
Inducing path
给观测端点 X,Y，路径内部每个非端点是碰撞点且为 X 或 Y 的祖先；它说明潜变量边际化后端点不能被任何观测集分离。
MAG
Maximal ancestral graph：任意不相邻节点都存在某集合将其 m-separate；若存在 inducing path，则补边至 maximal。
Discriminating path
形如 ⟨X,…,W,Y,Z⟩，X 与 Z 不相邻，W 前的内部点均为碰撞点且为 Z 的父；用于在没有普通未遮蔽三元组时判断 W 在 ⟨W,Y,Z⟩ 中是否为碰撞。
Partial mixed graph
边端可为尾、箭头或圆圈；圆圈表示等价类中该端点尚未确定。
PAG
代表一个 MAG Markov 等价类：相邻关系与所有成员一致；尾/箭头只在所有成员相同处固定，否则用圆圈。

2. PAG 中路径与可见边

Definitions 16.1.10–16.1.14
Uncovered path
每个连续三元组的首尾不相邻；避免隐藏弦干扰定向。
Collider / non-collider in PAG
两边都以箭头指向中点则确定为 collider；至少一边以尾离开中点则确定为 non-collider；圆圈组合可能不确定。
Possibly m-connecting path
给定 Z，路径上没有确定的非碰撞点落入 Z，且每个确定碰撞点可能为 Z 的祖先；表示某个等价类成员中路径可开放。
Definite m-connecting path
每个内部节点的 collider/non-collider 身份确定，并满足碰撞点有 Z 后代、非碰撞点不在 Z；在所有相容成员中提供更强连接证据。
Visibility
PAG/MAG 中 X→Y 若有不与 Y 相邻的节点 V 指向 X，或有以 X 为碰撞链且各中间点为 Y 父的路径，则边可见；可见表示该边不可能由潜在混杂单独解释。

3. Faithfulness

Definition 16.1.9 — Faithfulness分布中的全部条件独立都必须由图的 separation 蕴含；与 Markov 性合起来得到“图分离当且仅当统计独立”。它排除参数精确抵消。有限样本中只能近似检验，因此结构学习应报告阈值敏感性。

4. 已知干预靶点

Definitions 16.2.1–16.2.8
Soft intervention
替换目标节点条件机制而非固定常数；非靶点机制保持。
Symmetrical difference I△J
只在 I 或 J 之一出现的靶点集合；比较两个制度时，只有这些机制必然不同。
I-Markov property
每个制度内满足图 Markov；制度 I、J 之间，对不在 I△J 的机制施加相应跨分布不变约束，可用增强制度节点图统一表示。
I-Markov equivalence
两图对给定干预集合 I 蕴含同一组域内独立与跨制度不变。
Augmented diagram
为每个干预制度增加节点，指向其已知靶点；增强图中的 separation 编码 I-Markov 约束。
I-MAG
把增强图中的潜变量边际化并 maximal 化，保留制度节点与观测节点的可分离关系。
I-PAG
代表 I-MAG 等价类的部分图，显示干预后所有成员共同确定的端点。
I-faithfulness
观测与全部干预分布元组恰好满足 I-Markov 图所蕴含的约束，无额外抵消。

5. 未知或不完美靶点 Ψ

Definitions 16.2.9–16.2.15
Ψ-Markov property
给分布元组 P 与候选靶点集合 Ψ，用制度差异对应的增强图编码域内独立和跨分布机制不变；靶点本身也是待推断对象。
Ψ-Markov equivalence
图-靶点对 ⟨G,Ψ⟩ 对所有可观测约束给出相同集合。
Ψ augmented diagram
每对/每制度差异节点连接到候选改变机制；与已知 I 图不同，边取决于 Ψ。
Ψ-MAG / Ψ-PAG
分别是潜变量边际化后的 maximal 图及其等价类代表。
C-faithfulness
跨制度约束集合不仅满足 Ψ-Markov，而且任何观测到的不变都对应图中分离，排除跨分布抵消。
Ψ-PDAG
无潜变量时代表图-靶点对等价类的部分有向图；圆/无向端表示仍不确定。
