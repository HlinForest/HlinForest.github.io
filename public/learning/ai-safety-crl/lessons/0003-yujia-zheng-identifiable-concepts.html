Lesson 03

Yujia Zheng：让概念经得起环境变化

核心不是为 latent 起一个好听的名字，而是精确说明：在什么假设下，哪些潜在概念能被恢复到哪一种等价类。

20 分钟研究者桥接多分布 · 稀疏 · 可识别
本课胜利条件：面对一个“LLM 中发现了欺骗特征”的声明，你能提出至少三个可识别性压力测试，而不是只看重构损失或人工解释。

她的问题可以压缩成一句话

从复杂观测中，什么是真正可恢复的潜在概念或动态结构？若不能唯一恢复，还剩下什么等价类；加入哪种最弱额外信息，才能进一步识别？

Yujia Zheng 的官方研究定位是发展 causal representation learning 的基础，并把这些洞见带入 trustworthy machine learning、foundation models 与 world models。她的工作覆盖多分布 CRL、潜在概念非参数识别、时间因果表示，以及 LLM/SAE 中特征的一致性与结构。

例子：一个“欺骗特征”到底是什么

你对 agent 的隐藏激活训练 sparse autoencoder，得到 feature 417。它在包含隐藏意图的轨迹上高激活，自动解释器把它命名为“欺骗”。这还不能证明它就是欺骗概念。

至少有四个候选解释：

  1. 真实意图 C：agent 确实在隐藏目标；
  2. 表面风格 S：这些轨迹更常用保留、模糊措辞；
  3. 任务难度 D：困难任务同时诱发规划长度和高激活；
  4. 训练随机性 R：另一次 SAE 训练会把同一语义分散到别的特征。

把相关性叫作概念之前，需要设计跨环境比较，让 C、S、D 的变化不再总是绑定。

多分布 CRL：变化要“方向不同”，不只是“数量更多”

环境保持近似不变主动改变想排除的捷径
E₁ 原始轨迹基线无建立参照
E₂ 同意图改写隐藏意图措辞/语言表面风格
E₃ 同措辞换意图模板/长度目标是否隐藏模板词
E₄ 难度配平题目难度隐藏意图比例规划长度
E₅ 重训 SAE模型与数据随机种子训练偶然性

“充分变化”不是简单要求环境数多。十个环境若都只把同一个机制的方差乘二，提供的变化方向可能仍只有一个；约束矩阵的秩不够，其他潜在坐标仍可任意混合。

坏的多环境：10 次都只改变同一风格强度 → 新信息方向仍近似 1 好的多环境：独立改变措辞、意图、难度、时间结构 → 候选混合更难同时解释所有变化

ICML 2024 结果应该怎样准确复述

设定

多分布、完全非参数，不要求每次分布变化都是 hard intervention。

关键结构

恢复图的稀疏约束，以及潜在因果影响发生“足够变化”的条件。

一般结论

可恢复底层 DAG 的 moralized graph，并精确刻画恢复表示与真实模型的关系。

更强情形

在某些条件下，大多数潜变量可恢复到逐分量可逆变换；不是无条件恢复完整有向 DAG。

“多分布 CRL 已经证明能从任何 LLM 激活唯一恢复人类可读概念。”

错误。定理结论必须和假设、观测对象及剩余等价类一起报告。LLM 激活还涉及线性近似、特征规模、时间/瞬时关系、数据选择和有限样本误差。

从 CRL 到 mechanistic interpretability

SAE 常把高维激活拆成稀疏特征，但两个训练 run 可能给出不同 feature basis。若一次实验的“欺骗特征”在另一次训练中消失、拆分或与别的语义合并，针对它做 steering 的结论就不稳。

因此 safety 研究不应只测 interpretability（人能否给特征命名），还要测 consistency（跨 run/数据/环境是否对应同一因素） 与 causal validity（干预特征是否按预测改变下游行为）。

一份最小特征压力测试

  • 跨随机种子：最佳匹配 feature 的语义与激活是否一致？
  • 跨语言/改写：保持意图时，feature 是否稳定？
  • 负对照：保持表面词但改变意图，feature 是否跟着意图走？
  • 干预验证：抑制或放大 feature 后，目标行为是否改变而副作用可控？
  • 等价类声明：恢复的是单概念、子空间、Markov network，还是仅任务充分表示？

Yujia Zheng 的主页把 CRL 与可信机器学习、foundation/world models 明确相连；ICML 2024 论文给出非参数多分布设定下的稀疏/充分变化结果。把这些思想用于“欺骗 feature”是课程综合案例。关于 LLM 概念的时间与瞬时结构，可继续读 NeurIPS 2025 的 identifiable temporal-instantaneous representation；关于 SAE 稳定性，可读 2026 的 feature consistency 工作。
