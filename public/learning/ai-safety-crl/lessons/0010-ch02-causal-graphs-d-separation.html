链、叉、碰撞点：三块因果图积木

复杂因果图的统计行为，大多能拆回三种三节点结构。最反直觉的是碰撞点：不控制时堵路，一控制反而开路。

25 min原书 PDF 66–99不需要图论
学完你能：辨认 chain / fork / collider，判断“控制一个变量”会堵住还是打开关联路径。

三种积木

结构小图生活故事给定中间点后
链 chainX → M → Y下雨 → 路湿 → 打滑控制 M 会堵住这条路
叉 forkX ← C → Y高温 → 冰淇淋；高温 → 溺水控制 C 会堵住混杂路
碰撞 colliderX → C ← Y能力 → 录取 ← 关系控制 C 反而打开路

链：中介变量传递作用

安全训练链
安全微调 → 拒答倾向 → 有害输出下降。若把“拒答倾向”固定在同一水平，安全微调通过这条中介路径对输出的差异会消失。注意：这只堵住这一条路，图中若有其他路径仍可能相关。

叉：共同原因制造关联

原书医疗结构的简化
用药 ← 严重度 → 康复。重症同时更易用药、更难康复，于是用药和康复看起来负相关。若严重度被充分测量，按同一严重度比较可堵住这条后门路径。

碰撞点：筛选成功者会制造关联

录取悖论
能力和关系本来互不相关，都能提高录取率。只看已录取者：如果一个人能力一般，你会推测他关系更强；如果能力很强，则不必靠关系。因为你条件化了共同结果“录取”，原本无关的两个原因开始负相关。

“控制变量”不是永远正确

统计教材常说“控制更多变量”。因果图告诉你：控制 fork 的中心有帮助，控制 collider 的中心可能有害。

典型安全数据偏差：只分析“被安全过滤器标记的对话”。标记可能同时由真实危险度和某种写作风格造成：危险度 → 被标记 ← 风格。在被标记样本里，风格会与危险度产生人造关联，可能让审计员把一种口吻误当成危险原因。

d-separation：在图上判断信息能否通行

名字虽难，操作可以先理解为“检查 X 与 Y 的每条路径是否都被堵住”。

  1. 忽略箭头方向，列出 X 到 Y 的所有路径；箭头方向仍用于认出链/叉/碰撞。
  2. 路径上的非碰撞点若被条件化，这条路径被堵住。
  3. 路径上的碰撞点默认堵路；若条件化它或它的后代，路径反而打开。
  4. 若所有路径都堵住，就说 X 与 Y 被给定集合 Z d-separated；在满足 Markov 假设时，这预言相应条件独立。
练习 1：下雨 → 路湿 → 打滑

不控制路湿时，下雨与打滑有关。给定路湿后，这条链被堵住：在“路面同样湿”的组内，仅通过这条路径，下雨不再提供打滑信息。

练习 2：能力 → 录取 ← 关系

不看录取时，路径在碰撞点自动关闭。给定“已录取”后，路径被打开；能力和关系会产生条件依赖。

可检验含义与不能检验的方向

图会预言一些独立关系。例如纯链 X → M → Y 预言 X ⟂ Y | M。如果数据强烈反对，图或测量假设有问题。但 X → Y 与 X ← Y 通常产生同一组独立关系，仅靠被动观测无法区分方向；这会在第 16 章成为 Markov 等价类。
